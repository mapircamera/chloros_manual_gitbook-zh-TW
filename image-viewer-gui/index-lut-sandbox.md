# 索引/LUT 沙盒

「索引/LUT 沙盒」是 Chloros 影像檢視器側邊欄中的互動式工作區。 您可以選擇一個公式，將相機的通道綁定至該公式，使用漸層上色並調整數值範圍——操作過程中，影像會即時更新。自 1.2.0 版本起，您還可 **儲存所建立的內容**，無論是單張影像或整個專案，皆無需重新處理。

## 沙盒的用途

| 索引/LUT 沙盒（互動式）        | 專案處理（批次）       |
| -------------------------------------- | -------------------------------- |
| 每次處理一張影像，即時回饋  | 一次處理整個資料集     |
| 實驗性與迭代式             | 預先設定的參數          |
| 即時渲染；僅在您要求時儲存  | 始終寫入成品檔案      |
| 非常適合尋找合適的設定 | 設定確定後效果最佳 |

{% hint style="success" %}
**常規工作流程**：在「沙盒」中調整參數，直到視覺效果符合預期為止，接著可直接從「沙盒」匯出，或將相同的索引與 LUT 設定複製到 [專案設定](../project-settings/project-settings.md)，以便下次處理時將這些設定套用至每張影像。
{% endhint %}

## 開啟 Sandbox

1. 點擊網格中的任一張影像 — 它將在 **影像檢視器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 標籤頁中以全螢幕模式開啟
2. 若左側邊欄尚未開啟，請點擊 **影像檢視器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 圖示以滑出左側邊欄
3. 從右上角的圖層下拉選單中選擇多波段圖層 — 通常選擇 **RAW (反射率)**，因為基於經校準反射率計算出的折射率值在不同影像間具有可比性

側邊欄自上而下顯示：

* 影像名稱及其相機型號
* **匯出/儲存影像**按鈕 — 勾選**Index**或**LUT** 後才會顯示
* **Index**和**LUT** 核取方塊
* 指數設定面板
* 包含讀數、直方圖及 GSD 控制項的 **游標值** 面板

{% hint style="warning" %}
**不適用於單色相機。** 在單波段 LATTICE M3M 影像中，這兩項核取方塊均為停用狀態，並顯示工具提示 _「不適用於單色 (M3M) 感測器」_ — 單一波段上無法定義多波段索引。 若要從 M3M 相機計算索引，請將兩張或更多影像組合成對齊的多波段堆疊，並使用 LATTICE 索引引擎。
{% endhint %}

## 套用索引

1. 勾選側邊欄頂端的 **索引** 方塊
2. 從左側下拉選單中選擇您的相機濾鏡（`RGN`、`OCN`、`NGB`、`RGB`、 `RE`、`NIR`)
3. 從右側下拉選單中選擇一個索引公式 — 共有 27 種內建公式，以及您已儲存的任何自訂公式
4. 公式將以數學運算式形式顯示於下方，每個頻段插槽處皆有一個空圓圈。**將彩色通道圓圈拖曳至插槽上** 以進行綁定
5. 當公式所使用的每個插槽皆已綁定後，圖像將更新並顯示索引值
6. 將游標懸停在圖像上即可讀取數值；**游標數值**面板會新增一行索引，顯示游標所在位置的數值

雙擊已綁定的槽位即可清除綁定。公式尚未完成僅是拖曳過程中的正常狀態，並非錯誤 — 圖像僅會在公式完成後才會更新。

通道圓圈採用顏色編碼：紅色 = Red、綠色 = Green、藍色 = Blue、橘色 = Orange、青色 = Cyan、紫色 = NIR、洋紅色 = RE。**「游標值」**面板中的通道點和直方圖曲線亦採用相同的顏色。

### NDVI 範例

```

Formula: (NIR - Red) / (NIR + Red)

For a Survey3W RGN camera:
  NIR = 850 nm band
  Red = 661 nm band

Result range:          -1.0 to +1.0
Typical vegetation:     0.4 to 0.9
Stressed vegetation:    0.2 to 0.4
Bare soil:              0.0 to 0.2
Water:                 -0.1 to 0.1
```

如需完整的公式參考資料——包括所有三個預設清單以及各名稱的適用範圍——請參閱 [多光譜指數公式](../project-settings/multispectral-index-formulas.md)。

### 勾選「指數」但未使用 LUT 時

影像以 **灰階** 繪製，並在兩個閾值之間進行拉伸。這是刻意為之：指數影像屬於標量資料，而灰階正是其最真實的呈現方式。若需顯示色彩，請添加 LUT。***

## 使用 LUT（查表）**查表（LUT）** 會將索引值映射為顏色：輸入 NDVI 0.65，輸出特定的綠色。它並不會改變資料本身——而是改變您解讀資料的方式。

### 新增 LUT

1. 點擊公式下方的 <img src="../.gitbook/assets/image (1) (1) (1).png" alt="" data-size="line"> **「+ 新增 LUT」** 按鈕
2. 選擇顏色漸變

### 選擇顏色漸變

將游標懸停在 **漸變條**上以開啟預設清單 — Chloros 內建**七種** 漸變預設：

| # | 漸變                            | 形狀                                                               |
| - | ----------------------------------- | ------------------------------------------------------------------- |
| 1 | Red → Yellow → Green (**預設**)  | 發散型 — 符合常見的植被直覺，綠色 = 健康 |
| 2 | 紫色 → 黃色 → Green             | 發散型，低端色調明顯                                  |
| 3 | 棕色 → 白色 → Blue                | 圍繞淺色中點的發散型                                   |
| 4 | 黑色 → 紫色 → 粉紅色 → 淺黃色 | 序列型，由深至淺                                           |
| 5 | 紅色 → 黃色 → 藍色                 | 以淺色中點為中心的發散型                                   |Red|
| 6 | 紫色 → 藍色 → 綠色 → 黃色      | 序列型，由深至淺                                           |
| 7 | Orange → White → Purple             | 圍繞淺色中點呈發散狀                                   |

**發散型**漸變會將中性色置於視窗中央，當中點具有特定意義（例如閾值、基準日期）時，此種呈現方式效果良好。**順序型**漸變會單調地由深至淺變化，這對於僅有「更多」與「更少」之分的數量而言，可提供良好的可讀性。

每個預設值都有七個色彩停點。點擊預設值後，圖片會立即更新（當 LUT 方塊被勾選時）。

### 編輯色彩停點

漸變條下方有一排顏色色塊，每個色塊對應一個色點：

* **變更顏色**：點擊色塊以開啟選色器（色輪、RGB/HSV 滑桿，或十六進位碼，例如 `#FF0000`）
* **新增色階**：點擊該行末端的**+** 按鈕 — 將新增一個白色色階
* **移除色階**：**雙擊** 色塊
* **保留已編輯的漸變**：點擊漸變條旁的儲存圖示，將您編輯過的漸變新增至預設清單，以便日後再次選用

您在索引上設定的漸變會與該索引一同儲存於專案設定中，因此即使關閉並重新開啟專案，設定仍會保留。

**較少的色階**會產生分明且可視為分類的區域；**較多的色階**則會產生平滑、近乎照片般的過渡效果。三至五個色階適用於簡報投影片和分類地圖；六至十個色階適用於一般分析；十五個或更多則適用於詳細檢視及出版圖表。

### 設定數值範圍

閾值控制項是一個範圍從 −1 到 +1 的 **雙控點滑桿**，兩端各設有可編輯的文字方塊以輸入精確數值，並附有**AUTO** 按鈕。

* 拖曳任一滑桿，或在對應的文字方塊中輸入數字並按下 Enter
* **AUTO**會將範圍設定為影像有效指數值的**第 2 百分位數與第 98 百分位數** —— 這是忽略異常值的良好起點。 Chloros 會根據範圍自動調整結果的精確度：範圍極窄時保留 4 位小數，範圍較窄時保留 3 位小數，其他情況則保留 2 位小數
* 任何手動調整都將優先於 **AUTO**設定，直到您再次按下**AUTO** 按鈕為止

NDVI 視窗範例：

| 目標                                    | 最小值  | 最大值 |
| --------------------------------------- | ---- | --- |
| 顯示所有內容                         | −1.0 | 1.0 |
| 僅顯示植被，排除土壤與水域 | 0.2  | 0.9 |
| 僅顯示健康植被                 | 0.5  | 0.9 |
| 強調植被壓力                        | 0.2  | 0.5 |

縮小範圍會提高感興趣區域內的對比度，並將其他所有內容推至範圍之外——此時**裁剪模式**將決定這些內容的處理方式。***

## 裁剪模式

當像素的索引值超出最小/最大範圍時，裁剪模式將決定其繪製方式。

| 下拉選單標籤                  | 儲存值      | 超出範圍的像素將繪製為                                                                                                |
| ------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **最小值與最大值**（預設） | `clip`            | 漸層中最接近的端點顏色 — 小於最小值的數值採用第一種顏色，大於最大值的數值則採用最後一種顏色 |
| **透明背景**      | `transparent`     | 完全透明（真實透明度）                                                                                                  |
| **索引背景**| `indexColor`      | 灰階，延伸至影像的**完整**索引範圍，因此超出範圍的結構仍會以灰色顯示                |
| **原始背景**         | `backgroundColor` | 底層影像本身，因此色彩疊加層會覆蓋在真實場景之上                                                |

| 模式                       | 最適用於                               | 外觀                                      |
| -------------------------- | -------------------------------------- | ----------------------------------------- |
| **最小值與最大值**      | 完整資料顯示、科學分析 | 每個像素皆有顏色                      |
| **透明背景**           | GIS 疊加層、隔離特定數值區間   | 視窗內有顏色，視窗外無顏色 |
| **索引背景**       | 強調同時保留資料脈絡    | 範圍內為彩色，範圍外為灰色               |
| **原始背景**    | 報告與簡報              | 範圍內為彩色，範圍外為照片原貌         |

{% hint style="info" %}
**在所有模式下，無資料的像素始終呈透明狀。** 若像素的索引值非有限數（即 0/0 除法），或恰好為 −1.0 或 +1.0（飽和哨兵值，源於某個波段讀數為零而另一波段並非如此），則會被視為無資料，而非極值。 此機制可避免過曝的高光與死黑的陰影進入您的色彩階調範圍，而非將其描繪為畫面中最極端的讀數。同一規則亦定義了哪些像素會被納入 AUTO 閾值與索引直方圖的計算，因此這三者結果將保持一致。
{% endhint %}

當以 PNG 格式匯出時，透明度將被保留。此特性無法在 JPG 格式中呈現。

## 調整時的數值讀取

配置面板下方的 **游標數值** 面板是 Sandbox 的測量工具：

* 將游標移至影像上，即可讀取各通道的原始數值，以及其所在行中的索引值
* 啟用直方圖上方的 **INDEX** 按鈕，即可查看幀中索引值的分佈，其中兩個剪裁閾值會以橘色虛線標示，而游標的值則以白色實線顯示 — 這是選擇實際包含您資料的視窗最快速的方式
* 啟用 **CURSOR** 以在游標下方的數值處顯示標記線
* 放大至 60× 以上（若已設定 GSD 區塊大小，則放大倍率較低），以浮動數值標示個別顯示的像素

實用操作流程：

1. 記錄健康植被、受壓植被、裸土及水體上方的數值
2. 觀察這些聚類在指數直方圖上的位置
3. 設定最小值／最大值以涵蓋您關注的聚類範圍
4. 選擇裁切模式 — _原始背景_ 會保留其周圍場景的可見性

## 從 Sandbox 匯出

在您儲存之前，上述所有內容皆為即時預覽。側邊欄頂端的 **「匯出／儲存影像」** 按鈕會開啟一個滑出式面板，該面板會滑動覆蓋側邊欄（而非遮蓋影像，因此您仍可看到正在決策的內容）。

<figure><img src="../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>### 選項

| 選項                          | 效果                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **套用至當前影像**      | 根據這些設定，精確儲存目前顯示的影像                                                                                                |
| **套用至所有專案影像** | 對專案中的每張影像重新執行相同的設定。若影像缺少此索引所需的波段，則會被跳過，不會被視為失敗 |
| **索引/LUT 漸變條**      | 每次匯出時，還會另寫入一張標有數值範圍的圖例影像                                                                     |
| **索引直方圖**             | 每次匯出時，還會另寫入一張直方圖影像，顯示資料的最小值/最大值及剪裁閾值                                               |

若影像分頁的 **GSD 區塊大小** 大於 1，系統會在您確認前於面板中提示：此匯出將儲存您當前所見的內容，並包含區塊平均處理。若需完整解析度，請先將 GSD 控制項設回 1。

### 檔案儲存位置

每次點擊 **匯出**都會分配一個**全新的、絕不重複使用的資料夾**：

```
<project folder>/Sandbox_Exports/<IndexName>_<Index|LUT>_<NNN>/
```

範例：`Sandbox_Exports/NDVI_LUT_001/`，接著下一次執行會產生 `Sandbox_Exports/NDVI_LUT_002/`。編號是透過掃描磁碟上現有檔案生成的，因此即使重新啟動系統或手動刪除資料夾，編號仍會保留。 系統絕不會覆寫任何內容——沙盒的核心目的正是將當前嘗試與上一次的結果進行比較。

在資料夾內，每張影像對應的內容如下：

| 檔案                                                   | 內容                                                   |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `<source name>_<IndexName>_<Index\|LUT>.png`           | 渲染後的影像，與檢視器顯示的內容像素對像素完全一致 |
| `<source name>_<IndexName>_<Index\|LUT>_legend.png`    | 若已請求，則為漸變色條輔助檔案                     |
| `<source name>_<IndexName>_<Index\|LUT>_histogram.png` | 若已請求，則為索引直方圖輔助檔案                  |

這兩項附帶資料始終以 **全解析度** 寫入，即使主影像經過區塊平均處理亦然：區塊大小即為顯示解析度，且這兩項附帶資料皆讀取真正的每像素索引值。 它們所輸出內容也比螢幕顯示版本更完整 — 兩者皆會標註拉伸視窗範圍 _以及_ 真實資料的最小值與最大值，因此即使數月後未開啟該專案，儲存的圖例仍可清晰辨識。

### 進度與結果

整個專案的匯出僅需數分鐘，因此執行過程會透過即時進度頻道回報進度，而非阻塞程式：

* 進度條會顯示 `current / total` 以及正在寫入的檔案
* 完成時，窗格會顯示已匯出的影像數量、被跳過的影像數量，以及輸出資料夾路徑
* 被跳過的影像會連同原因一併列出（最多顯示五項，之後為「+N 項」一行）。常見原因通常是某個圖層缺乏此索引所需的通道
* 若專案中**沒有**任何影像能使用該索引，執行結果將顯示失敗，而非留下一個空資料夾

每次僅能執行一個沙盒匯出任務。若在某個任務執行中嘗試啟動第二個任務，系統會顯示明確訊息拒絕該操作，而非讓兩個執行任務爭奪同一個專案檔案。

### 網格會自動顯示執行結果

每個完成的執行任務都會以獨立按鈕的形式出現在 [影像網格](image-grid.md) 工具列中，標籤為 `<IndexName> <Index|LUT> <NNN>`。 這就是您比較執行結果的方式：使用不同的漸變或閾值進行兩次匯出，然後在網格上的兩個按鈕之間切換。

## 疑難排解

### 「此圖層沒有此索引所需的通道」

公式讀取了當前圖層所沒有的通道位置 — 例如在單通道或雙通道檔案上使用三槽索引。 請切換至多波段圖層（反射率或去拜耳化），或選擇符合您相機濾鏡的索引。

### 「無法連線至影像處理後端」

後端未回應。 請檢查「日誌」分頁；若後端正在重新啟動，待其恢復運作後，Sandbox 會自動恢復正常。

### 拖曳圓圈時影像未產生變化

公式尚未完成。不完整的公式會被視為正常的拖曳中狀態——既不會渲染，也不會報告為錯誤。 請填滿公式所使用的每個欄位。

### 整張影像呈現單一顏色

您的剪輯視窗可能遠遠超出資料範圍。按下 **AUTO**按鈕將其對齊至第 2 百分位數或第 98 百分位數，或開啟**INDEX** 直方圖以查看資料實際分布的位置。

### 匯出的顏色與我看到的不同

應該是一致的——匯出路徑是刻意鏡像呈現即時預覽的結果，包含剪裁模式的透明度，且區塊平均運算是在上色後才進行，這與檢視器的運作方式完全一致。 若出現差異，請確認在檢視與匯出過程中，GSD 區塊大小是否有所變更。
