# 以全螢幕模式開啟圖片

<figure><img src="../.gitbook/assets/image (34).png" alt=""><figcaption><p>以全螢幕模式開啟的影像，右上角顯示圖層選取器</p></figcaption></figure>

Chloros 影像檢視器是專用於檢視、檢查及測量影像的全螢幕介面。在此處，您可以讀取 **真實像素值** —— 包括各通道的數位數值 (DN)、反射率百分比，或以 W/m²/sr/nm 為單位的輻照度 —— 而非螢幕上顯示的拉伸預覽圖。

## 開啟影像檢視器

### 從檔案瀏覽器開啟

1. 開啟 **檔案瀏覽器** 標籤頁 <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">
2. 點擊 [影像網格](image-grid.md) 中的任何 **縮圖**

3. 影像將在**影像檢視器** 標籤頁中以全螢幕模式開啟

影像會開啟於網格原本顯示的任何產品上。若網格設定為 `RAW (Reflectance)`，則您將進入該圖層。

### 開啟「影像檢視器」側邊欄

點擊左側邊欄中的 **影像檢視器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 圖示，即可滑出分析面板。該面板自上而下包含：

* 影像名稱及其相機型號
* **匯出／儲存影像** 按鈕 （僅在啟用索引或 LUT 時顯示）
* **索引**和**LUT** 核取方塊，以及索引設定面板 — 請參閱 [索引/LUT 沙盒](index-lut-sandbox.md)
* **游標值** 面板：各通道讀數、圖層直方圖及 GSD 控制項***

## 導覽與縮放

### 瀏覽影像

* **下一張影像**：→ 按鈕，或**→**（右箭頭）鍵
* **上一張影像**：← 按鈕，或**←**（左箭頭）鍵
* **跳至特定影像**：返回網格並點擊其縮圖

在影像之間切換時，縮放與平移設定會維持不變，因此您可以在保持畫面同一區域的同時，逐步瀏覽整組影像。

### 縮放

縮放由 **滑鼠滾輪** 控制，以 15% 為單位調整，並以游標為錨點 — 游標下方的點會始終保持在游標正下方。 縮放範圍受影像與視窗大小限制：無法縮放至小於「適應視窗」的程度，且上限由影像的原生解析度決定。

全螢幕檢視器中沒有專用的縮放鍵。 （在網格中，**Ctrl + `+` / `−`** 可用於調整縮圖大小——這屬於另一種控制功能。）

### 縮放時的平移

在影像上點擊並按住滑鼠左鍵，然後拖曳。 平移範圍受限，因此無法將影像拖曳至螢幕外。

### 高倍放大時的逐像素檢視

當有效放大倍率超過 **60×** 時，Chloros 會在游標下方的單一顯示像素周圍繪製一個高亮方框，並在其旁邊顯示一個浮動數值。

"「有效」放大倍率會將 GSD 區塊大小納入計算：若區塊大小為 8，則高亮顯示會在 7.5× 放大倍率時出現，而非 60×，因為一個顯示像素已相當於 8 × 8 個原始像素。若將放大倍率縮回閾值以下，高亮顯示便會消失。

### 鍵盤快捷鍵

| 鍵                             | 位置       | 動作                              |
| ------------------------------- | ----------- | ----------------------------------- |
| **→**                           | 全螢幕 | 下一張影像                          |
| **←**                           | 全螢幕模式 | 上一張圖片                      |
| **Ctrl + R**                    | 全螢幕模式 | 重設索引/LUT 沙盒                 |
| **Ctrl + `+`**/**Ctrl + `=`** | 網格        | 放大縮圖（每次按下增加 4 像素）  |
| **Ctrl + `−`**                  | 網格        | 縮小縮圖（每次按下增加 4 像素） |

## 游標數值

將游標移至影像上方，**游標值** 面板便會顯示其下方每個通道的數值。

{% hint style="success" %}
**這些是檔案的實際數值。** 螢幕上的畫布是 8 位元的拉伸預覽，無法提供這些數值，因此 Chloros 會從實際產品檔案中擷取樣本以顯示讀數。這就是為什麼 12 位元原始影像會顯示大於 255 的數值，以及為什麼 float32 輻照度圖層會顯示物理單位。
{% endhint %}

### 各欄位的意義

此面板會根據您正在檢視的圖層進行調整：

| 您正在檢視的圖層              | 顯示的欄位    | 備註                                                                                           |
| ---------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| 反射率                        | **DN**和**%** | 百分比是根據該檔案自身的比例尺計算得出 — 詳見下文                                      |
| 輻度                           | **W/m²/sr/nm**   | 浮點數物理值；此處無 DN 欄位，因為 DN 在此處沒有意義                           |
| 原始 / 去拜爾化 / 預覽 / JPG    | **DN**           | 整數數位值                                                                         |
| 32 位元百分比反射率匯出 | 僅 **%**       | 儲存的浮點數並非 DN，因此若將其四捨五入為整數，將輸出無意義的 `0` 或 `1` |

每行均標有您相機濾鏡的通道名稱 — RGN 為 `Red / Green / NIR`、OCN 為 `Orange / Cyan / NIR`、NGB 為 `NIR / Green / Blue`， `Red / Green / Blue` 代表 RGB，而 RE、NIR 及單色 M3M 相機則標示單一波段名稱。每個標籤皆附有彩色圓點，其顏色與索引公式編輯器中使用的通道圓圈相符。

已儲存的 **索引與 LUT** 影像屬於特殊情況： 它們儲存的是色彩映射元件而非光譜波段，因此其行標籤為 `Red / Green / Blue`（若為單通道索引檔案則為 `Index`），而非相機的濾光片名稱。

當索引在沙盒中處於活躍狀態時，通道下方會出現額外一行，顯示游標處的 **索引值**，並附有索引名稱以及一個與直方圖上其標記相對應的白色圓點。

### 反射率百分比採用各檔案自身的比例尺

{% hint style="warning" %}
**請勿假設 65535 = 100%。** Chloros 會根據產生該資料的相機不同，以不同的比例尺儲存反射率，而檢視器會針對每個檔案解析出正確的比例尺。
{% endhint %}

| 來源                  | 對應反射率 1.0 的 DN 值 | 識別方式                                                                                                                               |
| ----------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LATTICE**(M3C / M3M) |**32768**                      | 每個 LATTICE 反射率匯出檔案中皆寫入 XMP 標籤 `Chloros:PixelScale=32768`。2× 的餘裕空間使檔案能承載大於 1.0 的 ρ 值而不產生剪裁 |
| **Survey3**|**65535**                      | 無 Chloros XMP 比例標籤 — Survey3 校準會寫入 ρ × dtype-max，並在 1.0 處進行裁剪                                                               |

檢視器、索引／LUT 沙盒以及索引匯出功能，皆透過同一個實作來解析比例，因此您在游標處讀取的數值，即為索引運算所使用的數值。

有兩點值得注意的後果：

* **32 位元百分比**TIFF 會將 DN/65535 儲存為浮點數，而**8 位元** PNG/JPG 匯出則儲存 DN × 255/65535 — 檢視器會在顯示百分比前將兩者轉換回原始值。
* 有一種情況無法恢復：**將 8 位元原始檔擷取內容以**8 位元TIFF**格式匯出** 時，其範圍會被裁剪為 0–255 而非重新縮放，且刻意不包含比例標籤。對於這類檔案，面板僅顯示 DN 值，不顯示百分比欄位。這是如實的呈現，並非錯誤。***

## 圖層直方圖

游標行下方是您正在檢視的圖層的即時直方圖，分為 **256 個區間**。預設情況下，它會繪製一條加權為 `(R + 2G + B) / 4` 的綜合曲線——這與 LATTICE 相機直方圖所使用的測量空間相同。 啟用**RGB** 後，將以各通道的顏色顯示各通道曲線，並以加法混合方式呈現，確保重疊部分仍可辨識。單色圖層始終繪製單一曲線。

橫軸採用圖層本身的單位：

| 圖層       | 軸單位  | 軸最大值                                               |
| ----------- | ---------- | ---------------------------------------------------------- |
| 反射率 | 百分比    | 125% — 產品的動態範圍允許 ρ 大於 1.0           |
| 輻照度    | W/m²/sr/nm | 該幀本身的峰值，向上取整至兩位有效數字 |
| 8 位元資料  | DN         | 255                                                        |
| 12 位元資料 | DN         | 4095                                                       |
| 16 位元資料 | DN         | 65535                                                      |

當軸線以 DN 為單位，且數值落在上述三個上限之一時，Chloros 也會知道您正在檢視的影像位元深度。

直方圖上方有三個按鈕：

| 按鈕     | 預設值 | 效果                                                                                                                                                                                                                                                                                                           |
| ---------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **游標** | 開啟      | 在直方圖上繪製標記線，位置精確對應上方行所顯示的數值，讓您能看到游標所在的像素在該幀的分布中位於何處。在RGB模式下，每個通道會以各自的顏色顯示一條標記線；否則則會根據綜合值顯示一條白色標記線 |
| **索引**| 開啟      | 僅在索引處於有效狀態時顯示。將直方圖從原始波段切換至**索引值分佈**，其中兩個剪裁閾值以橘色虛線標示，而游標的索引值則以白色實線顯示                                                          |
| **RGB**| 關      | 將顯示模式從合併曲線切換為各通道獨立曲線。在單色感測器上，此按鈕顯示為**MONO** 且處於停用狀態 — 因僅有一個通道可顯示                                                                                                                                  |

直方圖是根據 **您所看到的區塊** 計算的，而非其後方的原始像素：變更 GSD 區塊大小後，分佈會重新計算，因此直方圖、游標標記與顯示的影像始終一致。***

## GSD 區塊大小

面板底部是 **GSD (px)**控制項：包含一個數值輸入框、一個範圍從**1 到 256**的滑桿，以及一個**重設** 按鈕。

此功能會將 N × N 區塊的原始像素進行平均，並將其合併為一個顯示像素，藉此降低 _顯示_ 影像的解析度。`1` 為原生解析度。

* 此設定會影響 **全螢幕檢視、網格縮圖、游標讀數以及兩組直方圖** — 所有顯示影像的元素均採用相同的地面解析度。
* 此設定僅限於 **顯示**。影像處理與匯出過程不受影響。 唯一例外是刻意設計的：透過 [索引/LUT 沙盒](index-lut-sandbox.md) 進行匯出時，系統會儲存您當前所見的內容，因此會保留當前的區塊大小；當區塊大小超過 1 時，匯出面板會向您發出警告。
* 該值以 **按專案** 為單位儲存於 `viewer_display.gsd_bin` 中（位於 `project.json` 內），因此即使關閉並重新開啟軟體，該值仍會保留。
* 當區塊大小超過 1 時，游標讀數會顯示區塊值而非原始像素值——顯示的數值是游標所在區塊的平均值。

{% hint style="info" %}
**為何使用「區塊大小」而非每像素公分？** 若要計算每像素公分數，必須知道地面高度。單一影像的 EXIF 資料中記載的是 GPS 海拔高度（以平均海平面為基準），而非影像所對準的地形高度，因此 Chloros 不會顯示無法準確推算出的地面距離。 以原始像素為單位的區塊大小，正是 MAPIR 雲端工具在地面樣本距離未知時所採用的備用方案。
{% endhint %}

## 可檢視的影像類型

檢視器右上角的圖層下拉選單會列出當前影像的所有版本。顯示哪些項目取決於相機型號以及已處理的內容 —— 請參閱 [影像圖層](image-layers.md) 以查看完整清單及下拉選單的運作方式。

### Survey3

* **JPG** — 相機本身的預覽檔案
* **RAW (原始)** — 來源檔案 `.RAW`，已進行去拜耳化以供顯示，未經任何校正
* **RAW (標靶)** — 經識別為包含校準標靶的影像幀
* **RAW (反射率)** — 經校準的反射率產出結果（65535 = ρ 1.0）
* **暗角校正**/**感測器響應** — 未經校準的備用產出結果
* **白平衡** — 已進行白平衡處理的產出
* **RAW (`<INDEX>` 索引)**及**`<INDEX>` LUT** — 計算得出的索引影像

### LATTICE

LATTICE 的擷取操作使用相同的下拉式選單，其中包含處理流程的層級名稱：

| 層級                 | 所包含的內容                                                        |
| --------------------- | -------------------------------------------------------------------- |
| **RAW (原始)**    | 拍攝時的原始 RAW 幀                                     |
| **RAW (去拜耳化)**   | 線性去拜耳化影像                                           |
| **RAW (預覽)**     | 顯示預覽 — 多光譜相機的假色拉伸 |
| **白平衡**    | RGB 主相機的顯示預覽（白平衡 + 伽瑪校正）   |
| **RAW (輻照度)**    | 以 W/m²/sr/nm 為單位的 Float32 光譜輻照度                              |
| **RAW (反射率)** | uint16 反射率，32768 = ρ 1.0                                    |

輻度與反射率僅適用於多光譜：RGB 主相機不具備各波段輻度測量功能，因此不會為其產生這些圖層。

## 指數與 LUT 套用

從側邊欄套用多光譜指數與色彩查找表 (LUT)：

1. 開啟 **影像檢視器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 側邊欄
2. 勾選 **指數**

3. 選擇相機的濾鏡與指數公式，然後將通道圓圈拖曳至公式的插槽中
4. 新增 LUT 並選擇漸層、閾值及剪裁模式
5. 讀取游標位置的數值，並透過 **匯出／儲存影像** 儲存結果

請參閱 [指數／LUT 沙盒](index-lut-sandbox.md) 以查看完整操作指南。

## 疑難排解

### 無法開啟影像

**可能原因**：檔案在匯入後被移動或刪除；產品從未被寫入；處理超大影像時記憶體不足。**解決方法**：

1. 檢查該圖層的檔案是否仍存在於專案的輸出目錄中
2. 使用外部檢視器開啟檔案，以確認檔案是否完整
3. 關閉其他應用程式以釋放記憶體

### 影像呈現全黑、全白或色彩異常

**可能原因**：顯示拉伸功能無資料可處理（畫面幾乎恆定不變）；float32 圖層含有異常數值；索引未產生有效資料。**解決方法**：

1. 讀取光標值 — 若每個通道的數值皆為零或接近零，問題出在資料本身，而非顯示
2. 檢查直方圖：若某一端出現單一尖峰，表示該幀影像遭裁切或為空
3. 檢查產生該圖層之執行程序的處理日誌

### 數值看起來不對

**可能原因**：您所處的圖層與預期不同；您正在將百分比與原始動態範圍（DN）進行比較；您正在使用相同的除數，將 LATTICE 檔案與 Survey3 檔案進行比較。**解決方法**：

1. 確認下拉式選單中選取的圖層——面板的單位會隨圖層而變
2. 對於反射率，請使用 **%** 欄位，而非自行將 DN 除以某個數值；若必須進行除法運算，請使用該檔案的 `Chloros:PixelScale`（LATTICE 為 32768，若未指定則 Survey3 默認為 65535）
3. 將 GSD 區塊大小設回 1 —— 若大於 1，您讀取的是區塊平均值，而非單一像素
4. 確認該幀影像確實已執行反射率校正；未經校正的備用產品（感測器響應／暗角校正）並非反射率
