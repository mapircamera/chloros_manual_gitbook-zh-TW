# 将图像以全屏模式打开

<figure><img src="../.gitbook/assets/image (34).png" alt=""><figcaption><p>以全屏模式打开的图像，右上角显示图层选择器</p></figcaption></figure>

Chloros 图像查看器是用于查看、检查和测量图像的全屏界面。您可以在此读取 **真实像素值** ——包括各通道的动态范围（DN）、反射率百分比或辐射通量（W/m²/sr/nm）——而非屏幕上显示的拉伸预览图。

## 访问图像查看器

### 从文件浏览器进入

1. 打开 **文件浏览器** 选项卡 <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">
2. 点击 [图像网格](image-grid.md) 中的任意 **缩略图**

3. 图像将在**图像查看器** 选项卡中全屏打开

图像将打开在网格当前显示的任意产品上。如果网格设置为 `RAW (Reflectance)`，则您将进入该图层。

### 打开图像查看器侧边栏

点击左侧边栏中的 **图像查看器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 图标，即可展开分析面板。该面板从上到下包含：

* 图像名称及其相机型号
* **导出/保存图像**按钮（仅在启用索引或 LUT 时显示）
* **索引**和**LUT**复选框以及索引配置面板——参见 [索引/LUT 沙盒](index-lut-sandbox.md)
* **光标值**面板：各通道读数、图层直方图以及 GSD 控制***

## 导航与缩放

### 浏览图像

* **下一张图像**：点击 → 按钮，或按**→**（右箭头）键
* **上一张图像**：点击 ← 按钮，或按**←**（左箭头）键
* **跳转到特定图像**：返回网格视图并单击其缩略图

在图像之间切换时，缩放和平移设置会保持不变，因此您可以在保持画面同一区域的同时逐帧浏览整组图像。

### 缩放

缩放通过 **鼠标滚轮** 控制，以 15% 为增量，并以光标为中心——指针下方的点始终保持在指针下方。缩放范围受图像和窗口大小的限制： 无法缩小至“适应窗口”尺寸以下，且上限由图像的原生分辨率决定。

全屏查看器中没有专用的缩放键。（在网格视图中，**Ctrl + `+` / `−`** 可调整缩略图大小——这属于另一种控制方式。）

### 缩放时的平移

在图像上单击并按住鼠标左键，然后拖动。平移范围受限，因此无法将图像拖出屏幕。

### 高倍放大时的逐像素检查

当有效放大倍率超过 **60×** 时，Chloros 会在光标下方的单个显示像素周围绘制一个高亮框，并在其旁边显示一个浮动数值。

“有效”放大倍率以 GSD 块大小为基准：当块大小为 8 时，高亮效果会在 7.5× 放大倍率下出现，而非 60×，因为此时显示的单个像素已经相当于 8 × 8 个源像素。当缩小至阈值以下时，高亮效果将消失。

### 键盘快捷键

| 键                             | 位置       | 操作                              |
| ------------------------------- | ----------- | ----------------------------------- |
| **→**                           | 全屏模式 | 下一张图像                          |
| **←**                           | 全屏模式 | 上一张图像                      |
| **Ctrl + R**                    | 全屏模式 | 重置索引/LUT 沙盒         |
| **Ctrl + `+`**/**Ctrl + `=`** | 网格        | 显示更大缩略图（每次按键增加 4 像素）  |
| **Ctrl + `−`**                  | 网格        | 缩小缩略图（每次按键缩小 4 像素） |***

## 光标值

将光标悬停在图像上，**光标值**面板会显示其下方每个通道的数值。

{% hint style="success" %}
**这些是文件的实际数值。** 屏幕上的画布是经过拉伸的 8 位预览，无法提供这些数值，因此 Chloros 会从实际的产品文件中采样以显示读数。这就是为什么 12 位原始帧会显示大于 255 的数值，以及为什么 float32 辐射度图层会显示物理单位。
{% endhint %}

### 各列的含义

该面板会根据您当前查看的图层自动调整：

| 当前查看的图层              | 显示的列    | 备注                                                                                           |
| ---------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| 反射率                        | **DN**和**%** | 百分比值是根据该文件自身的比例尺计算得出的 — 详见下文                                      |
| 辐射度                           | **W/m²/sr/nm**   | 浮点物理值；无 DN 列，因为在此处 DN 没有意义                           |
| 原始 / 去拜耳化 / 预览 / JPG    | **DN**           | 整数数字                                                                         |
| 32 位百分比反射率导出 | **%** 仅限       | 存储的浮点数并非 DN，因此将其四舍五入为整数会输出毫无意义的 `0` 或 `1` |

每行都标有相机滤光片对应的通道名称——例如，RGN 对应 `Red / Green / NIR`， `Orange / Cyan / NIR` 对应 OCN，`NIR / Green / Blue` 对应 NGB， `Red / Green / Blue` 对应 RGB，RE、NIR 及单色 M3M 相机的单波段名称。 每个标签上都有一个彩色圆点，其颜色与索引公式编辑器中使用的通道圆圈颜色相匹配。

已保存的 **索引和 LUT** 图像属于特殊情况：它们包含色图组件而非光谱波段， 因此其行标为 `Red / Green / Blue`（或单通道索引文件的 `Index`），而非相机的滤光片名称。

当沙盒中启用了索引时，通道下方会出现一行额外内容，显示光标处的**索引值**，并附有索引名称以及一个与直方图上该索引标记相对应的白色圆点。

### 反射率百分比使用各文件自身的比例尺

{% hint style="warning" %}
**请勿假设 65535 = 100%。** Chloros 根据生成该文件的相机不同，以不同的量纲存储反射率，而查看器会针对每个文件解析出正确的量纲。
{% endhint %}

| 来源                  | 等于反射率 1.0 的暗数 (DN) | 识别方式                                                                                                                               |
| ----------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LATTICE**(M3C / M3M) |**32768**                      | 每个 LATTICE 反射率导出文件中都会写入 XMP 标签 `Chloros:PixelScale=32768`。 2×的余量使文件能够承载大于1.0的ρ值而不会被截断 |
| **Survey3**|**65535**                      | 无 Chloros XMP 比例标签 — Survey3 校准会写入 ρ × dtype-max，并在 1.0 处进行裁剪                                                               |

查看器、索引/LUT 沙盒以及索引导出均通过同一个实现来解析比例，因此您在光标处读取的值与索引计算所用的值是相同的。

有两点值得注意：

* **32 位百分比**的 TIFF 将 DN/65535 作为浮点数存储，而**8 位** 的 PNG/JPG 导出则存储 DN × 255/65535 ——查看器在显示百分比前会将两者均转换回原值。
* 有一种情况无法恢复：**8-bit TIFF 导出的 8位源文件**的**8位TIFF导出文件会被裁剪为0–255范围而非重新缩放，且刻意不包含缩放标签。对于此类文件，面板仅显示DN值，不显示百分比列。这是事实，并非错误。***

## 图层直方图

光标行下方是您正在查看的图层的实时直方图，包含 **256 个区间**。默认情况下，它会绘制一条加权合并曲线 `(R + 2G + B) / 4`——这与 LATTICE 相机直方图使用的测量空间相同。开启**RGB** 选项，将显示按通道绘制的曲线，这些曲线以通道颜色显示，并采用加法混合，以确保重叠部分仍可辨识。单色图层始终绘制单条曲线。

横轴采用图层自身的单位：

| 图层       | 轴单位  | 轴最大值                                               |
| ----------- | ---------- | ---------------------------------------------------------- |
| 反射率    | 百分比    | 125% — 该产品的动态余量允许 ρ 大于 1.0           |
| 辐射度    | W/m²/sr/nm | 帧本身的峰值，四舍五入至两位有效数字 |
| 8 位数据  | DN         | 255                                                        |
| 12 位数据 | DN         | 4095                                                       |
| 16 位数据 | DN         | 65535                                                      |

当坐标轴以 DN 为单位且数值达到上述三个上限之一时，Chloros 也会识别您正在查看的数据的位深度。

直方图上方有三个按钮：

| 按钮     | 默认值 | 效果                                                                                                                                                                                                                                                                                   |
| ---------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **光标** | 启用      | 在直方图上绘制标记线，位置与上行显示的精确数值完全对应，以便您查看光标所在像素在帧分布中的位置。 在 RGB 模式下，每个通道都有一个各自颜色的标记；否则，会在组合值处显示一个白色的标记 |
| **索引**| 开启      | 仅在索引处于活动状态时显示。将直方图从源波段切换为**索引值分布**，其中两个剪切阈值以橙色虚线显示，而光标的索引值则以白线显示                                                          |
| **RGB**| 关闭     | 在合并曲线与各通道曲线之间切换。在单色传感器上，此按钮显示为**MONO** 且处于禁用状态——因为只有一个通道可显示                                                                                                                                  |

直方图是基于**可见的块**计算的，而非其后方的源像素：更改 GSD 块大小后，分布会重新计算，因此直方图、光标标记和显示的图像始终保持一致。***

## GSD 块大小

面板底部是 **GSD (px)**控件：一个数值输入框、一个范围为**1 到 256**的滑块，以及一个**RESET** 按钮。

它通过将 N × N 块源像素平均为一个显示像素，从而降低_显示_图像的分辨率。`1` 为原生分辨率。

* 这会影响 **全屏视图、网格缩略图、光标读数以及两个直方图** ——所有显示图像的部分均采用相同的地面分辨率。
* 该设置仅**影响显示**。图像处理和导出操作不受影响。 唯一的一个例外是刻意设计的：通过 [索引/LUT 沙盒](index-lut-sandbox.md) 导出的文件会保存您当前所见的内容，因此会保留当前的块大小；当块大小超过 1 时，导出面板会向您发出警告。
* 该值以 **按项目** 的形式存储在 `viewer_display.gsd_bin` 中（位于 `project.json` 内），因此关闭并重新打开软件后仍会保留。
* 只要块大小大于 1，光标读数显示的便是块的数值，而非源像素的数值——显示的数值是光标下该块的平均值。

{% hint style="info" %}
**为什么是“块大小”而不是每像素厘米数？** 每像素厘米数需要地面以上的高度。 单帧的 EXIF 数据中包含相对于平均海平面的 GPS 海拔高度，而非相对于拍摄目标地形的相对高度，因此 Chloros 不会显示其无法准确推算出的地面距离。 以源像素为单位的块大小，正是 MAPIR 云端工具在地面采样距离未知时采用的备用方案。
{% endhint %}

## 可查看的图像类型

查看器右上角的图层下拉菜单列出了当前图像的所有版本。显示哪些条目取决于相机以及已处理的内容——请参阅 [图像图层](image-layers.md) 以获取完整列表及下拉菜单的工作原理。

### Survey3

* **JPG** — 相机生成的预览文件
* **RAW（原始）** — 源文件 `.RAW`，已进行去拜耳处理以便显示，未进行任何校正
* **RAW（目标）** — 被识别为包含校准目标的帧
* **RAW (反射率)** — 已校准的反射率结果（65535 = ρ 1.0）
* **暗角校正**/**传感器响应** — 未校准的备用结果
* **白平衡处理** — 经过白平衡处理的图像
* **RAW (`<INDEX>` 指数)**和**`<INDEX>` LUT** — 计算得出的指数图像

### LATTICE

LATTICE 的捕获操作使用相同的下拉菜单，其中包含处理流程的层级名称：

| 层                 | 包含的内容                                                        |
| --------------------- | -------------------------------------------------------------------- |
| **RAW（原始）**    | 捕获的源 RAW 帧                                     |
| **RAW（去拜耳化）**   | 线性去拜耳化图像                                           |
| **RAW（预览）**     | 显示预览 — 多光谱相机的伪彩色拉伸图像 |
| **白平衡**    | RGB 主摄像机的显示预览（白平衡 + 伽马校正）   |
| **RAW（辐射度）**    | 以 W/m²/sr/nm 为单位的 Float32 光谱辐射度                              |
| **RAW（反射率）** | uint16 反射率，32768 = ρ 1.0                                    |

辐射度和反射率仅适用于多光谱数据：RGB主相机不具备各波段辐射计量功能，因此不会为其生成这些图层。

## 指数和LUT应用

通过侧边栏应用多光谱指数和颜色查找表（LUT）：

1. 打开侧边栏中的 **图像查看器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line">
2. 勾选 **指数**

3. 选择相机的滤波器及指数公式，然后将通道圆圈拖拽到公式的插槽中
4. 添加 LUT，并选择渐变、阈值和剪切模式
5. 读取光标位置的数值，并通过 **导出/保存图像** 保存结果

完整操作指南请参见 [指数/LUT 沙盒](index-lut-sandbox.md)。

## 故障排除

### 无法打开图像

**可能原因**：文件在导入后被移动或删除；项目从未被写入；处理超大图像时内存不足。**解决方法**：

1. 检查该图层的文件是否仍存在于项目的输出树中
2. 在外部查看器中打开文件，确认文件是否完整
3. 关闭其他应用程序以释放内存

### 图像显示为黑色、白色或颜色异常

**可能原因**：显示拉伸没有可处理的内容（帧值几乎恒定）；float32图层包含异常值；索引未生成有效数据。**解决方法**：

1. 读取光标值——如果每个通道的值均为零或接近零，则问题出在数据上，而非显示端
2. 检查直方图：若某一端出现单个尖峰，则表明该帧被裁剪或为空
3. 检查生成该图层的运行处理日志

### 数值看起来有问题

**可能原因**：您当前所在的图层与您想象的不同；您正在将百分比与原始动态范围（DN）进行比较；您在使用相同除数的情况下，将 LATTICE 文件与 Survey3 文件进行比较。**解决方法**：

1. 在下拉菜单中确认所选图层——面板的单位随图层而定
2. 对于反射率，请使用 **%** 列，而非自行对 DN 进行除法运算；若必须进行除法运算，请使用该文件的 `Chloros:PixelScale` （LATTICE 为 32768，若未指定则 Survey3 为 65535）
3. 将 GSD 像元大小重置为 1 —— 若大于 1，则读取的是像元平均值，而非单个像素
4. 检查该帧是否确实进行了反射率校准；未经校准的备用产品（传感器响应/暗角校正）不属于反射率数据
