# 图像图层

图像查看器右上角的**图层下拉菜单**可在您正在查看的图像的所有版本之间进行切换——从源图像到每个处理后的产品，再到计算得到的索引图像——而无需离开查看器。

## 什么是图像图层？

在 Chloros 中，“图层”是指与一张原始图像关联的单个 **产品文件**。导入操作会提供原始文件；处理过程会为该运行生成的每个产品添加一个图层。 导出的文件保留源文件名——识别处理结果的是**文件夹**，而图层名称则是 Chloros 为该文件夹赋予的标签。

## 图层列表

### 始终存在

| 图层 | 说明 |
| --- | --- |
| **JPG**（或**PNG**/**TIFF**） | 随捕获数据导入的基础文件。Survey3 会将一个 `.JPG` 导入到每个 `.RAW` 旁边； LATTICE 捕获会带来一个 PNG 或 TIFF 显示预览。标签标注了实际导入的内容|
| **RAW（原始）** | 源原始帧，已进行去拜耳化以供显示，未应用任何校正。 导入后立即可用——无需任何处理 |

若 LATTICE 捕获的基准文件**即是**其原始帧，则无需单独的基准条目：`RAW (Original)` 已涵盖此情况。

### Survey3 处理结果

| 图层 | 写入至 | 存在于 |
| --- | --- | --- |
| **RAW（目标）** | — | 该帧被识别为包含校准目标 |
| **RAW（反射率）** | `Reflectance_Calibrated_Images/` | 该帧的反射率校准已成功运行 |
| **暗角校正**| `Vignette_Corrected_Images/` | 该帧无法进行反射率校准**且** *暗角校正* 功能已启用 |
| **传感器响应**| `Sensor_Response_Images/` | 该帧无法进行反射率校准**且** *暗角校正*功能处于关闭状态 |
| **已进行白平衡** | `White_Balanced_Images/` | 已生成白平衡处理后的图像 |

{% hint style="info" %}
**暗角校正和传感器响应是互斥选项，绝不能同时启用。** 每个运行、每种相机型号仅存在一个未校准的备用产品，而 *暗角校正* 开关决定选用哪一个。参见 [项目设置](../project-settings/project-settings.md)。
{% endhint %}

### LATTICE 层级

LATTICE 会在单次处理过程中将数据拆分到以下各层。具体包含哪些层，取决于“项目设置”中各产品的导出开关选项，以及相机适用的设置。

| 层级 | 写入到 | 适用对象 |
| --- | --- | --- |
| **RAW（去拜耳化）** | `Debayered_Images/` | RGB 和多光谱 |
| **RAW（预览）** | `Preview_Images/` | 多光谱（伪彩色拉伸） |
| **白平衡** | `Preview_Images/` | RGB 主摄像头 — RGB 预览已在此名称下注册，以便与同名的 Survey3 图层对齐 |
| **RAW（辐射度）** | `Radiance_Images/` | 仅限多光谱 |
| **RAW（辐射度）** | `Reflectance_Calibrated_Images/` | 仅限多光谱，且仅当存在匹配的 `.daq` 下行记录或通过质量检查（QA）的帧内目标覆盖该帧时 |

RGB主相机不具备各波段辐射测量功能，因此对其而言，辐射度和反射度将被标记为**不适用**而跳过——日志会明确记录此情况，而非静默失败。

### 索引、LUT 和沙盒图层

| 图层模式 | 示例 | 来源 |
| --- | --- | --- |
| **RAW (`<INDEX>` 索引)** | `RAW (NDVI Index)` | 每个索引对应一个，在“项目设置”中配置，处理过程中计算得出 |
| **`<INDEX>` LUT** | `NDVI LUT` | 索引的色彩映射版本 |
| **沙盒 (`<Name>` `<Index\|LUT>` `<NNN>`)** | `Sandbox (NDVI LUT 003)` | 每次 [索引/LUT 沙盒](index-lut-sandbox.md) 导出运行生成一个 |

如果同一索引名称被配置多次且设置不同，则第二个及后续的索引名称中会添加数字（`RAW (NDVI2 Index)`），以便区分各图层。

## 使用图层选择器

1. 点击网格中的缩略图，以全屏模式打开图像
2. 点击查看器右上角的 **图层下拉菜单**

3. 选择一个图层 — 图像会立即更新

下拉菜单中，**JPG、RAW（原始）、RAW（目标）、RAW（反射率）** 按此顺序优先显示，其余选项则按产品注册顺序排列。

### 浏览时的图层优先级

按下 **←**/**→** 可切换至下一张图像，并尝试保持在同一图层上：

1. **优先精确匹配** —— 如果下一张图像有同名的图层，则显示该图层。 正是这一机制确保您在浏览整套图像时始终停留在 `RAW (NDVI Index)` 层上
2. **其次按类型匹配** —— 索引层会查找任何索引层，LUT 会查找任何 LUT，反射率层会查找反射率层，目标层会查找目标层，原始层会查找原始层，基层会查找基层
3. **仅限导出图层** —— 即使图层列表尚未更新，名称也会被保留，因为文件已在磁盘上存在。这使得您可以在运行仍在写入数据时预览产品
4. **其他情况** —— 取第一个可用的图层，通常是基图

项目中的 `.daq` 和 `.csv` 旁路文件会被方向键导航跳过，因此逐帧浏览图像时不会停留在光传感器记录上。

缩放和平移操作也会在图像间延续，这使得对同一视野位置进行前后对比变得非常简单。

## 按图层理解像素值

[光标值面板](opening-an-image-full-screen.md#cursor-values) 会显示光标所在位置的实际每通道值，单位为该图层的存储单位。其列内容会随图层而变化：

| 图层 | 显示单位 | 备注 |
| --- | --- | --- |
| 基础图层（JPG / PNG / TIFF 预览） | DN，0–255 | 显示值，在 RGB 上经过伽马校正。仅供目视检查 |
| RAW（原始） | DN | 传感器原始数字值。直方图轴标注了深度：255（8 位）、4095（12 位）或 65535（16 位） |
| RAW（去拜耳化） | DN | 线性，无显示拉伸 |
| RAW（预览）/ 白平衡 | DN | 显示结果——经过拉伸或伽马校正。不可用于测量 |
| RAW（辐射度） | **W/m²/sr/nm** | Float32 物理辐射度。无 DN 列 |
| RAW（辐射度） | DN **和 %** | 百分比值基于该文件自身的量纲计算——详见下文 |
| 索引/LUT/沙盒导出 | 索引值，或 RGB 组件 | 单通道索引文件报告索引值； 色彩映射的 LUT 文件则报告 Red/Green/Blue 分量 |

### 反射率：比例尺因文件而异

{% hint style="warning" %}
**“除以 65,535”仅对 Survey3 有效。** LATTICE 的反射率采用不同的比例尺存储，混用这两个除数是导致反射率值恰好只有应有值一半的最常见原因。
{% endhint %}

| 来源 | 反射率为 1.0 的 DN | 标识符 |
| --- | --- | --- |
| **LATTICE**(M3C / M3M) |**32768** | 每个 LATTICE 反射率导出文件中都包含的 XMP 标签 `Chloros:PixelScale=32768`。 2×的余量意味着大于1.0的ρ值可以表示，而非被截断 |
| **Survey3**|**65535** | 若无 Chloros XMP 比例标签 — Survey3 校准会写入 ρ × dtype-max，并在 1.0 处截断 |

对于 GIS 和脚本：从文件中读取 `Chloros:PixelScale` 并以此除以该数值。如果该标签不存在，则文件采用 Survey3 比例 (65535)。查看器、索引/LUT沙盒以及索引导出功能均以相同方式解析该比例，因此光标处读取的数值即为索引计算所使用的数值。

在此比例基础上，针对不同格式的具体存储方式：

* **TIFF（32 位，百分比）** 将 DN / 65535 作为浮点数存储
* **PNG（8 位）**和**JPG（8 位）** 将动态范围值 (DN) × 255 / 65535 存储为浮点数
* **将 8 位源捕获数据导出为 8 位 TIFF 格式** 时，数据会被裁剪为 0–255 范围而非重新缩放，且故意不包含缩放标签。面板仅对这些文件显示 DN 值，不显示百分比列

### 索引值范围

| 索引类别 | 典型范围 | 读数 |
| --- | --- | --- |
| 归一化差值 (NDVI, GNDVI, NDRE, ENDVI…) | −1 至 +1 | 健康植被通常为 0.4–0.9；裸土接近 0；水体为负值 |
| 土壤校正（SAVI、OSAVI、MSAVI2…） | 大约 −1 至 +1.5 | 读数与 NDVI 相似，但抑制了土壤背景 |
| 比值（GRVI、GCI、MSR、CIRE…） | 上限无界 | 随着分母波段趋近于零，比值将无限增长 |
| EVI / LAI | 0 至 ~1，0 至 ~3.5 | 云层及其他饱和像素会导致两者均超出范围——请先对其进行遮罩处理 |

有关每个预设背后的精确公式，请参阅 [多光谱指数公式](../project-settings/multispectral-index-formulas.md)。

## 常见工作流程

### 处理前/后对比

1. 选择 **RAW（原始）**，并注意暗角和未校准的数值
2. 切换至 **RAW（反射率）**

3. 进行对比——暗角已消除，数值已校准。缩放和平移位置会保持不变，因此您看到的仍是同一片地面

### 检查整组图像中的某个索引

1. 打开第一张处理后的图像并选择索引图层
2. 反复按 **→** —— 索引图层会跟随您逐帧显示
3. 操作时观察侧边栏中的直方图：分布出现突变的帧值得仔细检查

### 验证校准目标

1. 在目标帧上选择 **RAW (Target)**

2. 确认目标清晰可见且已被检测到
3. 切换到下一帧目标——目标图层会随之移动

### 检查反射率值的准确性

1. 选择 **RAW (Reflectance)**

2. 阅读“光标值”面板中的**%** 列——该数值已针对该文件进行了正确缩放
3. 参照帧内已知材料进行合理性检查：健康的植被在 NIR 通道中值高，在红色通道中值低；校准目标的读数应接近其公布的反射率

## 故障排除

### 下拉菜单中未出现预期的图层

**可能原因**

* 图像从未经过处理——仅存在基图和 `RAW (Original)`
* 在“项目设置”中未勾选该产品的导出选项
* 该产品不适用于该相机（在 RGB 主相机上为辐射度和反射度；在单波段 M3M 单色相机上为任意指数）
* 反射率校准缺乏有效数据——既无 `.daq` 下行波覆盖，也无通过质量保证（QA）检测的帧内目标——因此该帧回退至“暗角校正”或“传感器响应”模式

**解决方法**

1. 检查运行日志：Chloros 会记录何时无法生成所请求的导出产品以及原因
2. 检查 [项目设置](../project-settings/project-settings.md) 中各产品的导出开关
3. 确认项目输出树中是否存在该产品文件夹
4. 启用该产品后重新处理

### 图层列表似乎已过时

Chloros 会在运行过程中重新扫描项目的产物文件夹，并根据磁盘上的实际内容修复缺失的图层注册信息，因此一个已正常导出的图层通常会单独出现在轮询结果中。切换出图像窗口后再切回，会强制进行新的解析。

### 反射率值仅为应有值的一半

您几乎可以肯定是在将 LATTICE 文件除以 65535。请使用 `Chloros:PixelScale` (32768)，或查看 **%** 列，该列已应用此值。

### 索引图层存在但图像为空白

该索引需要您的图层所不具备的波段——例如，将读取第三通道的索引应用于单通道或双通道文件。请切换到多波段图层（反射率或去拜耳化），或选择与相机滤光片相匹配的索引。
