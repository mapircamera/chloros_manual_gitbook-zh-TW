# 图像图层

图像查看器右上角的**图层下拉菜单**可在您正在查看的图像的所有版本之间进行切换——从源图像到每个处理后的产品，再到计算得出的索引图像——而无需离开查看器。

## 什么是图像图层？

在 Chloros

中，“图层”是指与一张源图像关联的某个 **产品文件**。导入操作会提供源文件；处理过程会为该运行生成的每个产品添加一个图层。 导出的文件保留源文件名——由**文件夹**来标识该产品，而图层名称则是Chloros

为该文件夹赋予的标签。

## 图层列表

### 始终存在

| 图层 | 类型 |
| --- | --- |
| **JPG**（或**PNG

**/**TIFF

**） | 随捕获数据导入的基础文件。Survey3

会将每个`.RAW`文件旁导入一个`.JPG`文件；LATTICE捕获数据会带来PNG

或TIFF

格式的显示预览。标签标注为实际导入的内容 |
| **RAW（原始）** | 源原始帧，已进行去拜耳处理以供显示，但未应用任何校正。自导入瞬间即可使用——无需任何处理 |

对于基础文件**即**为原始帧的 LATTICE 捕获数据，没有单独的基础条目：`RAW (Original)` 已涵盖该内容。

### Survey3

处理产品

| 图层 | 写入至 | 存在于 |
| --- | --- | --- |
| **RAW（目标）** | — | 该帧被识别为包含校准目标 |
| **RAW（反射率）** | `Reflectance_Calibrated_Images/` | 该帧的反射率校准已成功完成 |
| **暗角校正**| `Vignette_Corrected_Images/` | 该帧无法进行反射率校准**且** *暗角校正* 处于开启状态 |
| **传感器响应**| `Sensor_Response_Images/` | 该帧无法进行反射率校准**且** *暗角校正* 处于关闭状态 |
| **已进行白平衡** | `White_Balanced_Images/` | 已生成白平衡处理后的产品 |

{% hint style="info" %}
**暗角校正和传感器响应是互斥选项，绝不会同时启用。** 每个运行中，针对每种相机型号仅存在一个未校准的备用产品，而 *暗角校正* 开关将决定选用哪个。参见 [项目设置](../project-settings/project-settings.md)。
{% endhint %}

### LATTICE 级别

LATTICE 在单次处理过程中将数据拆分到以下级别。具体包含哪些级别取决于“项目设置”中各产品的导出开关，以及相机适用的设置。

| 图层 | 写入目标 | 适用对象 |
| --- | --- | --- |
| **RAW（去拜耳化）** | `Debayered_Images/` | RGB

和多光谱 |
| **RAW（预览）** | `Preview_Images/` | 多光谱（伪彩色拉伸） |
| **白平衡** | `Preview_Images/` | RGB

主相机——RGB

预览以该名称注册，以便与同名的Survey3

图层保持一致 |
| **RAW（辐射度）** | `Radiance_Images/` | 仅限多光谱 |
| **RAW（辐射度）** | `Reflectance_Calibrated_Images/` | 仅限多光谱，且仅当存在匹配的 `.daq` 下行记录或通过质量保证（QA）的帧内目标覆盖该帧时 |

RGB

主相机不支持各波段辐射计量，因此对其而言，辐射度和反射度会被标记为**不适用**而跳过——日志中会明确记录此情况，而非静默失败。

{% hint style="info" %}
**原始和去拜耳化图层与产品对齐（1.3.0 版新增功能）。**LATTICE 原始和去拜耳化文件以传感器原生方向保存，并在 XMP 中记录其所属的方向；其他产品则在保存时已应用该方向。 查看器和图像网格会根据该记录将**RAW（原始）**和**RAW（去拜耳化）** 层进行显示对齐，因此当您在生成图层和原始图层之间切换时，画面不再翻转。这仅影响显示效果——文件本身绝不会被重写。 未记录方向信息的文件（在 1.3.0 之前拍摄或由其他软件写入）将按存储时的原始方向显示。请参阅 [输出图像格式](../output-image-formats.md#orientation)。
{% endhint %}

钳位蒙版（位于 `clamp_masks/` 文件夹中的 `*_clampmask.tif`）并非图层：Chloros

在导入时会跳过它们。请参阅 [输出图像格式](../output-image-formats.md#clamp-masks)。

### 索引、LUT 和沙盒图层

| 图层类型 | 示例 | 来源 |
| --- | --- | --- |
| **RAW（`<INDEX>` 索引）** | `RAW (NDVI Index)` | 每个索引对应一个（在“项目设置”中配置），在处理过程中计算得出 |
| **`<INDEX>` LUT** | `NDVI LUT` | 索引的色彩映射版本 |
| **沙盒 (`<Name>` `<Index\|LUT>` `<NNN>`)** | `Sandbox (NDVI LUT 003)` | 每个 [索引/LUT 沙盒](index-lut-sandbox.md) 导出任务 |

如果同一索引名称被配置多次且设置不同，则第二个及后续的索引名称中会添加数字（`RAW (NDVI2 Index)`），以便区分各图层。

## 使用图层选择器

1. 点击网格中的缩略图，以全屏模式打开图像
2. 点击查看器右上角的 **图层下拉菜单**

3. 选择一个图层——图像会立即更新

下拉菜单中，**JPG、RAW（原始）、RAW（目标）、RAW（反射率）** 按此顺序优先显示，其余选项则按产品注册顺序排列。

### 浏览时的图层优先级

按下 **←**/**→** 可切换到下一张图像，并尝试保持在同一图层上：

1. **优先精确匹配** —— 如果下一张图像包含同名的图层，则显示该图层。 正是这一机制确保您在浏览整套数据时始终停留在 `RAW (NDVI Index)` 层上
2. **随后按类型匹配** —— 索引层会查找任何索引层，LUT 层会查找任何 LUT 层，反射率层会查找反射率层，目标层会查找目标层，原始层会查找原始层，基底层会查找基底层
3. **仅限导出图层** —— 即使图层列表尚未同步，也会保留该名称，因为文件已在磁盘上存在。这使得您可以在运行仍在写入数据时预览产品
4. **其他情况** —— 首个可用的图层，通常是基图

项目中的 `.daq` 和 `.csv` 旁路文件会被方向键导航跳过，因此逐帧浏览图像时不会停留在光传感器记录上。

缩放和平移操作也会在图像间延续，这使得同一视野位置的“前后”对比变得非常直观。

## 按图层理解像素值

[光标值面板](opening-an-image-full-screen.md#cursor-values) 会显示光标所在位置的实际逐通道值，单位为该图层的存储单位。其列内容会随图层而变化：

| 图层 | 显示单位 | 备注 |
| --- | --- | --- |
| 基础（JPG / PNG

/ TIFF

预览） | DN，0–255 | 显示值，已对 RGB

进行伽马校正。仅供目视检查 |
| RAW（原始） | DN | 传感器原始数字值。直方图轴显示位深度：255（8 位）、4095（12 位）或 65535（16 位） |
| RAW（去拜耳化） | DN | 线性，无显示拉伸 |
| RAW（预览）/ 白平衡 | DN | 显示结果——经过拉伸或伽马校正。不可用于测量 |
| RAW（辐射度） | **W/m²/sr/nm** | Float32 物理辐射度。无 DN 列 |
| RAW（反射率） | DN **和 %** | 百分比值基于该文件自身的标度计算得出——详见下文 |
| 索引 / LUT / 沙盒导出 | 索引值，或 RGB

分量 | 单通道索引文件报告索引值；色彩映射的 LUT 文件报告 Red

/Green

/Blue

分量 |

### 反射率：比例尺因文件而异

{% hint style="warning" %}
**“除以 65,535”仅对 Survey3

有效。** LATTICE 的反射率采用不同的比例尺存储，混用这两种除数是导致反射率值恰好只有应有值一半的最常见原因。
{% endhint %}

| 来源 | 反射率为 1.0 的动态范围 (DN) | 标识为 |
| --- | --- | --- |
| **LATTICE**(M3C / M3M) |**32768** | 每个 LATTICE 反射率导出文件中都包含的 XMP 标签 `Chloros:PixelScale=32768`。2× 的余量意味着 ρ 大于 1.0 的值可以表示，而不会被截断 |
| **Survey3**| **65535** | 无 Chloros

XMP 比例标签 — Survey3

校准会写入 ρ × dtype-max，并在 1.0 处截断 |

用于 GIS 和脚本编写：从文件中读取 `Chloros:PixelScale` 并以此除以该值。 如果该标签不存在，则文件采用Survey3

比例尺（65535）。查看器、索引/LUT沙盒以及索引导出功能均以相同方式解析该比例尺，因此光标处显示的数值即为索引计算所使用的数值。

在此比例基础上，不同格式有特定的存储方式：

* **TIFF

（32位，百分比）** 将动态范围（DN）除以 65535 后以浮点数存储
* **PNG

（8位）**和**JPG（8位）** 将动态范围（DN）乘以 255 后除以 65535 进行存储
* **8 位采集生成的 8 位 DN 值**，或 1.3.0 版本之前写入的反射率文件，会被裁剪为 0–255 范围，且不包含比例标签。面板仅对这些文件显示 DN 值，不显示百分比列

### 指数值范围

| 指数类别 | 典型范围 | 读数 |
| --- | --- | --- |
| 归一化差值（NDVI

、GNDVI

、NDRE

、ENDVI…） | −1 至 +1 | 健康植被通常为 0.4–0.9；裸露土壤接近 0；水体为负值 |
| 土壤校正型（SAVI

、OSAVI

、MSAVI2…） | 大约 −1 至 +1.5 | 读数与 NDVI

相似，但抑制了土壤背景 |
| 比值型（GRVI

、GCI

、MSR、CIRE…） | 上限无界 | 随着分母波段趋近于零，比值会无限增大 |
| EVI

/ LAI

| 0 至 ~1，0 至 ~3.5 | 云层和其他饱和像素会导致两者超出范围——请先对其进行遮罩处理 |

有关每个预设背后的精确公式，请参阅 [多光谱指数公式](../project-settings/multispectral-index-formulas.md)。

## 常见工作流程

### 处理前/后对比

1. 选择 **RAW（原始）**，注意暗角现象及未经校准的数值
2. 切换至 **RAW（反射率）**

3. 进行对比——暗角已消除，数值已校准。缩放和平移操作会保持同步，因此您看到的仍是同一片地面

### 审查整组图像中的某个指数

1. 打开第一张处理后的图像并选择指数图层
2. 反复按 **→** 键——指数图层将随您逐帧跟随
3. 操作过程中观察侧边栏中的直方图：分布出现突变的帧值得仔细检查

### 验证校准目标

1. 在目标帧上选择 **RAW (Target)**

2. 确认目标清晰可见且已被检测到
3. 切换到下一帧目标——目标图层会随之移动

### 检查反射率值的准确性

1. 选择 **RAW (Reflectance)**

2. 查看“光标值”面板中的**%** 列——该数值已针对该文件正确缩放
3. 参照帧内已知材料进行合理性检查：健康的植被在NIR

波段反射率高，在红光波段反射率低；校准目标的读数应接近其公布的反射率

## 故障排除

### 下拉菜单中未出现预期的图层

**可能原因**

* 该图像从未经过处理——仅存在基底图层和 `RAW (Original)`
* 在“项目设置”中，该产品的导出开关未被勾选
* 该产品不适用于该相机（RGB

主相机上的辐射度和反射率；单波段 M3M 单色相机上的任何指数）
* 反射率校准缺乏校准依据——既无 `.daq` 下行覆盖数据，也无通过质量检查的帧内目标——因此该帧回退到了“暗角校正”或“传感器响应”模式

**解决方法**

1. 检查运行日志：Chloros

会说明何时无法生成请求的导出产品以及原因
2. 检查 [项目设置](../project-settings/project-settings.md) 中各产品的导出开关
3. 确认项目输出树中是否存在该产品文件夹
4. 启用该产品后重新处理

### 图层列表似乎已过时

在运行过程中，Chloros

会重新扫描项目的产出文件夹，并根据磁盘上的实际内容修复缺失的图层配准，因此已正常导出的图层通常会单独出现在一次轮询中。切换出图像窗口再切回会强制进行新的解析。

### 反射率值仅为应有值的一半

您几乎可以肯定是在将 LATTICE 文件除以 65535。请使用 `Chloros:PixelScale` (32768)，或查看 **%** 列，该列已应用此值。

### 索引图层存在但图像为空白

该索引需要您的图层所不具备的波段——例如，将读取第三个通道的索引应用于单通道或双通道文件。请切换到多波段图层（反射率或去拜耳化），或选择与相机滤光片相匹配的索引。
