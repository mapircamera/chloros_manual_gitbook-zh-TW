# 影像圖層

影像檢視器右上角的 **圖層下拉選單**，可讓您在不離開檢視器的情況下，在您正在檢視的影像所有版本之間切換——從原始擷取影像，到每個處理後的產品，再到計算出的索引影像。

## 何謂影像圖層？

在 Chloros 中，「圖層」是指針對單一原始影像進行配準的 **產品檔案**。匯入操作會提供原始檔案；處理過程則會針對該執行程序產生的每個產品新增一個圖層。 匯出的檔案會保留原始檔名——由**資料夾** 來識別該產品，而圖層名稱則是 Chloros 為該資料夾所標示的標籤。

## 圖層清單

### 始終顯示

| 圖層 | 內容 |
| --- | --- |
| **JPG**（或**PNG**/**TIFF**） | 隨擷取資料一併導入的基礎檔案。Survey3 會將每個 `.RAW` 旁導入一個 `.JPG`；LATTICE 擷取資料則會帶來 PNG 或 TIFF 顯示預覽。標籤內容為實際導入的檔案 |
| **RAW（原始）** | 來源的原始幀，已進行去拜耳化以供顯示，但未施加任何校正。自匯入當下即可使用——無需任何處理 |

若 LATTICE 擷取資料的基礎檔案**即是**其原始影像，則無需另設基礎項目：`RAW (Original)` 已涵蓋此部分。

### Survey3 處理產出

| 圖層 | 寫入至 | 存在於 |
| --- | --- | --- |
| **RAW (目標)** | — | 該影像被識別為包含校準目標 |
| **RAW (反射率)** | `Reflectance_Calibrated_Images/` | 此影像已成功執行反射率校準 |
| **暗角校正**| `Vignette_Corrected_Images/` | 該幀無法進行反射率校正**且** *暗角校正* 功能已啟用 |
| **感測器響應**| `Sensor_Response_Images/` | 此幀無法進行反射率校正**且** *暗角校正* 處於關閉狀態 |
| **已進行白平衡** | `White_Balanced_Images/` | 已寫入白平衡處理後的產品 |

{% hint style="info" %}
**「暗角校正」與「感測器響應」是互斥選項，絕不會同時啟用。** 每台相機型號在每次執行時，僅會產生一個未校正的備用產品，而 *暗角校正* 開關將決定採用哪一個。請參閱 [專案設定](../project-settings/project-settings.md)。
{% endhint %}

### LATTICE 層級

LATTICE 會在單次處理過程中將資料拆分至以下層級。實際存在的層級取決於「專案設定」中各產品的匯出開關，以及相機的適用設定。

| 圖層 | 寫入至 | 適用於 |
| --- | --- | --- |
| **RAW（去拜耳化）** | `Debayered_Images/` | RGB 和多光譜 |
| **RAW（預覽）** | `Preview_Images/` | 多光譜（假色拉伸） |
| **白平衡** | `Preview_Images/` | RGB 主相機 — RGB 預覽以此名稱註冊，以便與同名的 Survey3 圖層對應 |
| **RAW（輻射度）** | `Radiance_Images/` | 僅限多光譜 |
| **RAW（輻照度）** | `Reflectance_Calibrated_Images/` | 僅限多光譜，且僅當有相符的 `.daq` 下行記錄，或通過品質保證（QA）的幀內目標覆蓋該幀時適用 |

RGB 主相機不具備各波段輻射計量功能，因此其輻度與反射率將被標記為 **不適用** 而跳過 — 日誌會明確記錄此狀況，而非靜默失敗。

{% hint style="info" %}
**原始檔與去拜耳化圖層會與產品對齊（1.3.0 版新增功能）。**LATTICE 的原始檔與去拜耳化檔案會以感測器的原始方向儲存，並在 XMP 中記錄其對應的方向；其餘產品則在儲存時已套用該方向。 檢視器與影像網格會根據該記錄，將**RAW (原始)**和**RAW (去拜耳化)** 層進行對齊顯示，因此當您在產品層與原始層之間切換時，畫面將不再翻轉。此為純顯示功能 — 檔案絕不會被覆寫。 未記錄方向資訊的檔案（於 1.3.0 版本之前拍攝，或由其他軟體寫入）將以儲存時的原始狀態顯示。請參閱 [輸出影像格式](../output-image-formats.md#orientation)。
{% endhint %}

夾持遮罩（位於 `clamp_masks/` 資料夾中的 `*_clampmask.tif`）並非圖層：Chloros 在匯入時會跳過它們。請參閱 [輸出影像格式](../output-image-formats.md#clamp-masks)。

### 索引、LUT 和沙盒圖層

| 圖層類型 | 範例 | 來源 |
| --- | --- | --- |
| **RAW (`<INDEX>` 索引)** | `RAW (NDVI Index)` | 每個在「專案設定」中配置的索引對應一個，於處理過程中計算得出 |
| **`<INDEX>` LUT** | `NDVI LUT` | 索引的色彩映射版本 |
| **沙盒 (`<Name>` `<Index\|LUT>` `<NNN>`)** | `Sandbox (NDVI LUT 003)` | 每個 [索引/LUT 沙盒](index-lut-sandbox.md) 匯出執行 |

若同一索引名稱被配置多次且設定不同，則第二個及後續的索引名稱中會加入數字 (`RAW (NDVI2 Index)`)，以便區分各圖層。

## 使用圖層選擇器

1. 點擊網格中的縮圖，以全螢幕模式開啟影像
2. 點擊檢視器右上角的 **圖層下拉選單**

3. 選擇一個圖層 — 影像會立即更新

下拉選單會依序將 **JPG、RAW（原始）、RAW（目標）、RAW（反射率）** 列於最前，其餘項目則依產品註冊順序排列於後。

### 瀏覽時的圖層優先順序

按下 **←**/**→** 可切換至下一張影像，並會盡量維持在同一圖層上：

1. **優先精確匹配** —— 若下一張影像有名稱相同的圖層，系統將切換至該圖層。 這正是讓您在瀏覽整組影像時，能始終停留在 `RAW (NDVI Index)` 層的原因
2. **接著依類型匹配** — 索引層會搜尋任何索引層、LUT 會搜尋任何 LUT、反射率層會搜尋反射率層、目標層會搜尋目標層、原始層會搜尋原始層、基層會搜尋基層
3. **僅限匯出圖層** — 即使圖層清單尚未同步完成，系統仍會保留該名稱，因為檔案已存在於磁碟上。這正是讓您能在運算仍在寫入產品時，便能預覽產品的原因
4. **其他情況** — 選擇第一個可用的圖層，通常是基礎影像

專案中的 `.daq` 和 `.csv` 附屬檔案會被方向鍵導覽跳過，因此逐張瀏覽影像時絕不會停留在光感測器記錄上。

縮放與平移功能亦會跨影像套用，這使得同一視野位置的「前後」比較變得直觀簡便。

## 按圖層理解像素值

[游標值面板](opening-an-image-full-screen.md#cursor-values) 會顯示游標所在位置的實際每通道數值，單位為該圖層儲存時所採用的單位。其欄位會隨圖層而變：

| 圖層 | 顯示單位 | 備註 |
| --- | --- | --- |
| 基礎（JPG / PNG / TIFF 預覽） | DN，0–255 | 顯示值，已針對 RGB 進行伽瑪校正。僅供視覺檢查 |
| RAW（原始） | DN | 感測器的原始數位數值。直方圖軸標示位元深度：255（8 位元）、4095（12 位元）或 65535（16 位元） |
| RAW（去拜耳化） | DN | 線性，無顯示拉伸 |
| RAW（預覽）／白平衡 | DN | 顯示產出值 — 經拉伸或伽瑪校正。不適用於測量 |
| RAW（輻照度） | **W/m²/sr/nm** | Float32 物理輻照度。無 DN 欄位 |
| RAW（反射率） | DN **及 %** | 根據該檔案自身比例計算的百分比 — 詳見下文 |
| 索引 / LUT / 沙盒匯出 | 索引值，或 RGB 成分 | 單通道索引檔案報告索引值；色彩映射的 LUT 檔案報告 Red /Green /Blue 成分 |

### 反射率：比例尺因檔案而異

{% hint style="warning" %}
**「除以 65,535」僅適用於 Survey3。** LATTICE 的反射率是以不同的比例尺儲存的，混用這兩種除數是最常見的導致反射率值僅為應有數值一半的情況。
{% endhint %}

| 來源 | 對應反射率 1.0 的 DN | 識別方式 |
| --- | --- | --- |
| **LATTICE**(M3C / M3M) |**32768** | 每個 LATTICE 反射率匯出檔中皆標記有 XMP 標籤 `Chloros:PixelScale=32768`。2× 的預留空間意味著 ρ 大於 1.0 的數值可被表示，而非被截斷 |
| **Survey3**| **65535** | 無 Chloros XMP 比例標籤 — Survey3 校準會寫入 ρ × dtype-max，並在 1.0 處進行裁剪 |

針對 GIS 與腳本應用：從檔案中讀取 `Chloros:PixelScale` 並以此數值進行除法運算。 若該標籤不存在，則檔案採用Survey3 比例尺（65535）。檢視器、索引／LUT 沙盒以及索引匯出功能皆以相同方式解析此比例尺，因此游標處讀取的數值即為索引運算所使用的數值。

在此比例基礎上，各格式有其特定的儲存方式：

* **TIFF（32 位元，百分比）** 將 DN / 65535 儲存為浮點數
* **PNG（8 位元）**和**JPG（8 位元）** 儲存 DN × 255 / 65535
* **8 位元擷取所產生的 8 位元 DN 值**，或是在 1.3.0 版本之前寫入的反射率檔案，其範圍會被裁剪為 0–255，且不帶有比例標籤。面板僅會針對這些檔案顯示 DN 值，不會顯示百分比欄位

### 指數值範圍

| 指數類別 | 典型範圍 | 讀數 |
| --- | --- | --- |
| 歸一化差異 (NDVI、GNDVI、NDRE、ENDVI…) | −1 至 +1 | 健康植被通常為 0.4–0.9；裸露土壤接近 0；水體為負值 |
| 土壤校正型（SAVI、OSAVI、MSAVI2…） | 大約 −1 至 +1.5 | 讀數與 NDVI 相似，但抑制了土壤背景 |
| 比值型（GRVI、GCI、MSR、CIRE…） | 無上限 | 當分母波段趨近於零時，比值會無限增長 |
| EVI / LAI | 0 至 ~1，0 至 ~3.5 | 雲層及其他飽和像素會使兩者超出範圍 — 請先對其進行遮罩處理 |

有關每個預設值背後的精確公式，請參閱 [多光譜指數公式](../project-settings/multispectral-index-formulas.md)。

## 常見工作流程

### 處理前後比較

1. 選擇 **RAW（原始）**，並留意暗角現象及未校正的數值
2. 切換至 **RAW (反射率)**

3. 進行比較 — 暗角已消除，數值已校正。縮放與平移位置會保持不變，因此您所看到的仍是同一片地面

### 檢視整組影像中的單一指數

1. 開啟第一張處理後的影像，並選取指標圖層
2. 反覆按下 **→** —— 指標圖層會隨您逐張影像跟隨
3. 操作時請留意側邊欄的直方圖：若某幀的直方圖分佈出現跳躍，則值得進一步檢視

### 驗證校準目標

1. 在目標幀上選取 **RAW (Target)**

2. 確認目標清晰可見且已被偵測到
3. 移至下一幀目標 — 目標圖層會隨之跟隨

### 檢查反射率數值的準確性

1. 選取 **RAW (Reflectance)**

2. 閱讀「游標值」面板中的**%** 欄位 — 該欄位已針對該檔案正確進行了縮放
3. 對照畫面中的已知材料進行合理性檢查：健康的植被在NIR 波段值高，而在紅光波段值低；校準目標的讀數應接近其公佈的反射率

## 疑難排解

### 下拉選單中未出現預期圖層

**可能原因**

* 影像從未經過處理 — 僅存在基底圖層與 `RAW (Original)`
* 在「專案設定」中，該產品的「匯出」開關未勾選
* 該產品不適用於該相機（RGB 主影像上的輻照度與反射率；單波段 M3M 單色相機上的任何指數）
* 反射率校正缺乏校正依據 — 既無 `.daq` 下行輻射覆蓋範圍，亦無通過品質保證（QA）的幀內目標 — 因此該幀回退至「暗角校正」或「感測器響應」模式

**解決步驟**

1. 檢查執行日誌：Chloros 會標示何時無法輸出所請求的產品，並說明原因
2. 檢查 [專案設定](../project-settings/project-settings.md) 中各產品的匯出開關
3. 確認該產品資料夾是否存在於專案輸出目錄樹中
4. 啟用該產品後重新處理

### 圖層清單看似已過時

在執行過程中，Chloros 會重新掃描專案的產品資料夾，並根據磁碟上的實際內容修復缺失的圖層對位，因此已正常完成匯出的圖層通常會自行出現在輪詢結果中。若切換離開影像畫面再切回，會強制進行新的解析。

### 反射率數值似乎只有應有值的一半

您幾乎可以確定是將 LATTICE 檔案除以 65535。請使用 `Chloros:PixelScale` (32768)，或參閱已套用此設定的 **%** 欄位。

### 索引圖層存在但影像為空白

該索引需要您的圖層所沒有的波段 — 例如，將讀取第三通道的索引套用至單通道或雙通道檔案。請切換至多波段圖層（反射率或去拜耳化），或選擇符合相機濾鏡的索引。
