# 地圖標記

「地圖」分頁會根據影像的 GPS 座標，將影像標示在互動式 2D 地圖上。此功能可讓您掌握拍攝時段的地理概況，也是在匯入後，最快速篩除不需要處理影像的方式。

<figure><img src="../.gitbook/assets/chloros_map_markers.gif" alt=""><figcaption></figcaption></figure>

## 開啟「地圖」分頁

1. 在 Chloros 中開啟或建立一個專案
2. 匯入包含 GPS 元資料的影像
3. 點擊左側邊欄中的 **地圖** <img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> 分頁
4. 地圖上會於每張影像的 GPS 位置顯示一個標記

{% hint style="info" %}
**需具備 GPS 資訊**：僅有 EXIF 元資料中包含 GPS 座標的影像才會顯示在地圖上。沒有座標的影像仍會保留在專案中，並照常進行處理——只是地圖上不會顯示標記。
{% endhint %}

***

## 從「地圖」分頁調整圖片**地圖**<img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> 分頁與 [**檔案瀏覽器**](../processing-images-gui/adding-files-to-a-project.md) <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 分頁一樣，具備新增 <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> 及移除 <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> 檔案按鈕。它顯示相同專案檔案清單，並包含地理欄位：

| 欄位        | 內容                                                           |
| ------------- | ------------------------------------------------------------------ |
| **名稱**      | 從相機讀取的原始檔案名稱                             |
| **緯度**  | 十進制度數，小數點後六位                                |
| **經度** | 十進制度數，小數點後六位                                |
| **海拔**  | 公尺，保留一位小數 — 若影像未包含海拔資料，則顯示為 `-` |

{% hint style="info" %}
點擊任何欄位標題即可依該欄位排序；再次點擊則可反向排序。
{% endhint %}

{% hint style="warning" %}
**海拔是指海平面以上的高度，而非地面以上的高度。** 此數值來自影像的 EXIF `GPSAltitude` 標籤，該標籤以平均海平面為基準。 這並非相對於地表的飛行高度，且 Chloros 不會據此推算地面樣本距離——在海拔 300 公尺的田野上空，一架飛行高度為 100 公尺 AGL 的無人機，此處記錄的地面樣本距離約為 400 公尺。請將此欄位用於辨識異常值並確認飛行高度的一致性，而非作為 AGL 測量值使用。
{% endhint %}

## 影像標記

每張附有 GPS 資料的影像，其座標位置都會標示一個標記。

### 標記顯示

* 標記會精確位於每張影像記錄的座標位置
* 當縮放比例較大時，距離過近的標記可能會在視覺上重疊 — 請放大以區分它們
* 已選取並高亮顯示的標記會繪製在其他標記之上

### 懸停預覽

* **將游標懸停**在任何標記上，即可彈出該影像的縮圖及其檔案名稱
* **點擊**標記可選取該影像，並將彈出視窗**固定** — 視窗將保持開啟，直到您點擊其他位置為止。當彈出視窗被固定時，即使將游標懸停在其他標記上，也不會取代該視窗
* 這是無需離開地圖，即可在大型拍攝集裡快速找到特定一幀影像的捷徑

<figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption><p>「地圖」分頁會繪製專案中所有帶有地理標籤的影像</p></figcaption></figure>

### 超級縮放

{% hint style="success" %}
**超級縮放**：當您達到圖塊供應商所提供影像的最高縮放等級時，繼續放大會使圖塊進一步放大而非停止，因此您可以區分那些幾乎重疊在一起的標記。
{% endhint %}

* 超級縮放僅在您**位於**該位置的提供者最大縮放級別且圖塊已載入完成時才會啟用。若未達此級別，縮放行為將維持正常
* 範圍為提供者自身最大縮放級別之上的 **1× 至 32×*** 角落的指示器會以百分比顯示當前的超級縮放倍率，旁邊的 **×** 按鈕可讓您一鍵返回正常縮放狀態
* 縮放出去時會始終傳遞至地圖本身，因此您絕不會卡在超級縮放狀態中
* 在超級縮放狀態下進行縮放與平移時，系統會將產生的偏移量傳回地圖，因此您移動至的非中心區域會持續請求圖塊，而非變為空白
* 標記以向量元素繪製而非柵格化，因此在任何超級縮放層級下都能保持清晰

## 地圖圖塊提供者

{% hint style="success" %}
**自動選取**：Chloros 會根據您的影像所在位置，選擇提供最佳縮放層級的圖塊服務。您可隨時手動切換。
{% endhint %}

| 供應商        | 備註                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Google 地圖** | 全球廣泛覆蓋；支援所有四種圖塊類型                                                                                                            |
| **Esri ArcGIS**| 特定區域通常提供更高解析度的航空影像。Esri 不提供**地形** 圖塊類型，且在選取 Esri 時，該按鈕將被停用 |***

## 地圖圖塊類型

請透過按鈕（由左至右）選擇地圖圖層類型：

![](&lt;../.gitbook/assets/image (14).png&gt;)

| 類型                 | 顯示內容                                                                |
| -------------------- | -------------------------------------------------------------------- |
| **地形**          | 帶有地圖細節（道路、標籤）的高程陰影圖。僅限 Google       |
| **地圖**              | 標準街道地圖圖塊 — 頻寬需求最低的選項              |
| **衛星**        | 詳細衛星影像，無標籤 — 此為最耗頻寬的選項 |
| **混合** (預設) | 衛星影像上疊加道路與標籤                |

「地圖」分頁預設開啟於 **混合模式**。您的選擇將套用至支援此功能的服務供應商切換。***

## 地圖導航

* **縮放**：滑鼠滾輪，或地圖上的縮放按鈕
* **平移**：點擊並拖曳
* **全螢幕**：全螢幕控制項可將地圖擴展至整個視窗***

## 應用情境

### 飛行路徑檢視

* 一目瞭然地查看無人機任務的覆蓋範圍
* 找出遺漏航段的空缺處
* 確認飛行是否遵循預定路徑

### 地面測量審查

* 查看地面拍攝影像的分布情況
* 定位校準標靶相框相對於測量區域的位置
* 決定何處需要額外拍攝

### 品質控制

* 找出在意外位置拍攝的影像，並在處理前將其移除
* 依高度排序，以找出在錯誤高度拍攝的影像，或 GPS 定位不準確的影像
* 將影像位置與現場筆記進行交叉比對

***

## 疑難排解

### 未顯示標記點

**可能原因**

* 影像未包含 GPS 元資料
* 拍攝時相機的 GPS 功能已關閉
* 匯入前 EXIF 資料已被其他軟體移除

**解決方法**：確認相機的 GPS 功能已啟用，並重新匯入原始檔案。 您可透過「地圖」分頁中的檔案表格檢查特定檔案是否具有座標——若影像無座標，該表格中將不會有對應的資料列。

### 標記位置不正確

**可能原因**：拍攝時衛星定位不準確，或拍攝過程中 GPS 發生漂移。**解決方法**：這是拍攝時的問題，而非 Chloros 事後能修正的狀況。若需高精度作業，請使用 PPK/RTK GPS 工作流程——請參閱 [專案設定](../project-settings/project-settings.md) 中的**套用 PPK 修正** 設定。

### 地圖為空白或圖塊停止載入

圖塊供應商為線上服務。若圖塊停止傳輸，請檢查裝置的網路連線，然後嘗試切換供應商。若您當時處於極高縮放比例，請按下 **×** 重設按鈕以返回正常縮放比例，並讓地圖重新請求圖塊。***
