# 地图标记

“地图”选项卡会根据图像的 GPS 坐标，将它们标注在交互式 2D 地图上。它为您提供了拍摄 session 的地理概览，也是在导入后最快速剔除不需要处理的图像的方式。

<figure><img src="../.gitbook/assets/chloros_map_markers.gif" alt=""><figcaption></figcaption></figure>

## 访问“地图”选项卡

1. 在 Chloros 中打开或创建一个项目
2. 导入包含 GPS 元数据的图像
3. 点击左侧边栏中的 **地图** <img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> 选项卡
4. 地图上会在每张图像的 GPS 位置显示一个标记

{% hint style="info" %}
**需有 GPS 数据**：只有 EXIF 元数据中包含 GPS 坐标的图像才会显示在地图上。没有坐标的图像仍保留在项目中，并会照常处理——只是不会显示标记。
{% endhint %}

***

## 通过“地图”选项卡调整图片**地图**<img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> 选项卡与 [**文件浏览器**](../processing-images-gui/adding-files-to-a-project.md) <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 选项卡一样，都提供了添加 <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> 和删除 <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> 文件按钮。它显示的项目文件列表与文件浏览器相同，并包含地理位置列：

| 列        | 内容                                                           |
| ------------- | ------------------------------------------------------------------ |
| **名称**      | 相机导出的原始文件名                             |
| **纬度**  | 十进制度数，保留六位小数                                |
| **经度**  | 十进制度数，保留六位小数                                |
| **海拔**  | 米，保留一位小数 — 若图像未包含海拔信息，则显示为 `-` |

{% hint style="info" %}
点击任意列标题可按该列排序；再次点击可反向排序。
{% endhint %}

{% hint style="warning" %}
**海拔是指海拔高度，而非地面高度。**该值来自图像的 EXIF `GPSAltitude` 标签，该标签以平均海平面为基准。 这并非相对于地表的飞行高度，且 Chloros 不会据此推算地面采样距离——在海拔 300 米的田野上空，一架飞行高度为 100 米 AGL 的无人机在此处记录的地面采样距离约为 400 米。 请将该列用于识别异常值并确认飞行高度的一致性，而非作为AGL测量值使用。
{% endhint %}

## 图像标记

每张带有GPS数据的图像都会在其坐标处生成一个标记。

### 标记显示

* 标记位于每次拍摄记录的精确坐标位置
* 缩小地图时，相邻标记可能在视觉上重叠——请放大地图以区分它们
* 选中并高亮显示的标记会显示在其他标记之上

### 悬停预览

* 将鼠标悬停在任何标记上，会弹出该图片的缩略图及其文件名
* **单击**标记可选中该图像并将弹出窗口**固定**——该窗口将保持显示，直到您单击其他位置。当弹出窗口被固定时，悬停在其他标记上不会使其消失
* 这是在大型拍摄会话中快速查找特定帧的便捷方式，无需离开地图

<figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption><p>“地图”选项卡会绘制项目中所有带有地理标签的图像</p></figcaption></figure>### 超级缩放

{% hint style="success" %}
**超级缩放**：当您达到图块提供商支持的最大缩放级别后，继续放大会使图块进一步放大而非停止，从而帮助您区分几乎重叠的标记。
{% endhint %}

* 超级缩放仅在您**处于**该位置的提供商最大缩放级别且图块已加载完毕时才会激活。低于该级别时，缩放行为保持正常
* 缩放范围为提供商自身最大缩放级别之上的**1× 至 32×*** 角落处的指示器以百分比形式显示当前超级缩放倍数，其旁边的 **×** 按钮可一键恢复为正常缩放
* 缩小操作始终会传递到地图本身，因此您绝不会被卡在超级缩放状态中
* 在超级缩放状态下进行缩放和平移时，系统会将产生的偏移量反馈给地图，因此您移动到的偏离中心区域会持续请求图块，而非显示为空白
* 标记以矢量元素形式绘制而非栅格化，因此在任何超级缩放级别下都能保持清晰

## 地图图块提供商

{% hint style="success" %}
**自动选择**：Chloros 会根据您的图像所在位置，自动选择提供最佳缩放级别的图块服务。您可以随时手动切换。
{% endhint %}

| 提供商        | 备注                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Google 地图** | 全球覆盖范围广；支持全部四种图块类型                                                                                                            |
| **Esri ArcGIS**| 特定区域通常提供更高分辨率的航拍影像。Esri 不提供**地形** 图块类型，且在选择 Esri 时该按钮将被禁用 |***

## 地图图块类型

使用按钮（从左到右）选择地图图层类型：

![](&lt;../.gitbook/assets/image (14).png&gt;)

| 类型                 | 显示内容                                                                |
| -------------------- | -------------------------------------------------------------------- |
| **地形**          | 带地图细节（道路、标签）的高程阴影图。仅限 Google       |
| **地图**              | 标准街道地图图块 — 带宽需求最低的选项              |
| **卫星**        | 详细的卫星图像，无标签 — 带宽需求最高的选项 |
| **混合**（默认） | 卫星图像上叠加道路和标签                |

“地图”选项卡默认打开在 **混合** 模式下。您的选择将在支持该功能的提供商之间自动应用。***

## 地图导航

* **缩放**：鼠标滚轮，或地图上的缩放按钮
* **平移**：点击并拖动
* **全屏**：全屏控件可将地图扩展至整个窗口***

## 应用场景

### 飞行路径审查

* 一目了然地查看无人机飞行任务的覆盖范围
* 发现遗漏航段的空缺区域
* 确认飞行是否遵循了预定路线

### 地面测绘审查

* 查看地面拍摄图像的分布情况
* 定位校准目标帧相对于测绘区域的位置
* 确定需要补充拍摄的区域

### 质量控制

* 查找在意外位置拍摄的图像，并在处理前将其删除
* 按高度排序，以发现高度错误或GPS定位不佳的图像
* 将图像位置与实地笔记进行交叉核对

## 故障排除

### 未显示标记点

**可能原因**

* 图像中不包含 GPS 元数据
* 拍摄时相机上的 GPS 功能被禁用
* 导入前 EXIF 数据已被其他软件删除

**解决方法**：确认相机上的GPS已启用，并重新导入原始文件。您可以在“地图”选项卡的文件表中查找特定文件以确认其是否包含坐标——没有坐标的图像在该处不会显示行。

### 标记位置错误

**可能原因**：拍摄时卫星定位不佳，或拍摄过程中GPS发生漂移。**解决方法**：这是拍摄时的问题，而非Chloros可在事后纠正的问题。 如需高精度作业，请使用 PPK/RTK GPS 工作流——请参阅 [项目设置](../project-settings/project-settings.md) 中的**应用 PPK 校正** 设置。

### 地图空白或图块停止加载

图块提供商是在线服务。如果图块停止加载，请检查设备的网络连接，然后尝试切换提供商。如果您处于超大缩放级别，请按 **×** 重置按钮返回正常缩放级别，让地图重新请求图块。***
