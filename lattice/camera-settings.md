# 摄像机设置

“**摄像机**”选项卡是 Chloros

用于 LATTICE 摄像机的实时控制界面：主画面区域以实时磁贴的形式显示所有已连接的摄像机，侧边栏可在三个页面之间滑动切换——**摄像机列表**、**设置面板**（单个摄像机、阵列或采集设置——每次仅显示一种）以及**索引计算器**。本页面详细说明了摄像机列表、单个摄像机设置面板和阵列设置面板中的所有控件。采集模式、 导出类型选择以及“全景捕捉”流程，请参阅配套页面 [捕捉设置与模式](capture.md)。

当 Chloros

后端就绪后，“摄像机”选项卡将出现在侧边栏中。以下所有控件均通过 `127.0.0.1:5000` 与本地后端通信；除非另有说明，否则更改将立即应用于实时摄像头。

### 直播图块

每台摄像机都会渲染一个复合实时图块；此外，每台摄像机还可以显示三个灰度 **按通道分割** 的图块（参见 [通道分割](#display-overlays-drawn-over-the-live-feed))，而阵列则渲染一个组合图块。活动图块上会显示一个以摄像机（或阵列）颜色为底色的选中环。

将鼠标悬停在图块上会显示一个 **X** 关闭按钮：

* 在其通道分割图仍显示时关闭 **合成** 图块，仅会隐藏该合成图块。
* 关闭 **独立摄像头的最后一个可见图块** 会断开该摄像头的连接。
* **组合阵列成员的分割图块绝不会断开** 摄像头连接——它们仅会隐藏。

解锁网格后，可将任意图块拖动到任意插槽；布局将随项目一起保存。

### 摄像头行

每行摄像头显示一条颜色编码的边框（摄像头的自定义颜色）、一个“CAM”标签——其中数组成员带有蓝色 **M**（主）或绿色**S**（从）角色字母——以及显示名称。默认名称为 `LATTICE-MODEL (serial)`；可在“每台摄像机设置”窗格中重命名。行按钮：

| 按钮 | 效果 |
| --- | --- |
| **眼睛图标**| 切换可见性。隐藏的摄像头将从网格中移除，并**不被纳入“全景捕获”**。 |
| **齿轮** | 打开单个摄像头的设置面板（下一节）。 |
| **暂停 / 播放**|**仅在显示端**冻结实时预览——后端抓取仍会继续运行。暂停的摄像头无法进行捕获。 |
| **X** | 断开连接。UI 会立即更新（乐观估计）； 后端断开连接本身可能需要 10–30 秒才能完成。 |

### 数组行

数组行会显示一个以数组颜色呈现的“ARRAY”标识、数组名称（可在数组设置中重命名）以及一个 **DAQ · 开/关** 按钮——当数组级别的光传感器已设置 *或* 任何成员摄像头具有独立传感器时，该按钮显示为 **开**； 其工具提示会精确列出哪个传感器向哪个设备传输数据。成员摄像头以缩进形式列在其下方，并各自拥有独立的行。 数组行按钮：**眼睛图标**（批量隐藏/显示所有成员）、**齿轮图标**（数组设置面板）、**X**（断开整个数组连接）。

数组行和数组设置面板中显示的光传感器（DLS）状态有四种：**关闭**、**等待**（尚未收到光谱）、**活动**（最近 3 秒内收到光谱）以及**过期**——3 秒内未收到新光谱，但最后一次读数*仍被使用* （在捕获路径上，DAQ读数永不过期）。

在您重新排序之前，列表会先显示阵列，然后是独立相机，其中相机（以及每个阵列的成员）按**相机顺序**排列： M3C（拜耳）排在 M3M（单色）之前；在 M3C 之后依次为 FRGB、FRGN、FOCN，然后是 FNGB； M3M 按滤光片波长排序，波长最短的排在最前。网格的默认布局遵循相同的顺序。您可以在侧边栏中拖动独立相机和整个阵列组使其相互交叉，以重新排序列表；阵列成员无法单独拖动。

会将增益维持在0 dB，直到曝光时间达到允许的最长值（即AE上限、数组的触发周期或DAQ曝光上限）；只有此时增益才会上升。在数组中，触发率优先：自动曝光会先填满该触发率所对应的周期，随后才提高增益，因此场景变暗不再降低自动触发率（在 1.2.0 版本中会降低）。若阵列成员的**手动**曝光时间超过触发周期，则会减慢阵列的触发速率以适应该曝光时间； 当所有导致触发率降低的成员均恢复自动曝光后，自动触发率将恢复。当**曝光**和**AE目标亮度**均设为“自动”，且数据采集（DAQ）光传感器提供读数时，一旦自动曝光稳定，只要测得的光照值保持在约±25%范围内，每台相机的曝光值将保持不变； 若出现较大且持续的光照变化、设置重启（例如 ROI 变更）或您手动更改了曝光参数，系统将重新启动自动曝光。
{% endhint %}

{% hint style="info" %}
**自动曝光的行为方式（1.3.0）。**

* 手动曝光后，增益将保持在“自动”状态，直到您更改增益。
* 微小的高光不会使场景变暗：占画面面积不超过 1% 的镜面高光将被忽略；在已知校准目标的面板中，单个面板内不超过 0.5% 的区域亦被忽略。
* DAQ 曝光上限仅在校准目标处于视野内时生效；当未检测到任何面板时，相机将根据场景进行曝光。
* 在光线恒定的情况下，曝光保持稳定；光线发生大幅变化后，曝光会在几秒内稳定下来。过曝不再永久限制曝光，且当感兴趣区域（ROI）发生变化时，系统会重新确定曝光值。
* 亮度目标不会超出相机的，因此光线恢复时不会导致画面过曝。
* 若相机在强阳光下自动曝光停止响应，系统将根据光线传感器（或未连接传感器时，根据相机自身的帧数据）读取当前光照水平， 并在光线变化时释放该曝光值。光线传感器处于黑暗或被遮挡的状态不会影响此过程。
{% endhint %}

#### ROI 编辑器

1.3.0 版本新增功能。ROI 裁剪行及其下方的地图协同工作：

* **ROI 开启 / ROI 关闭**——**立即**启用或禁用传感器裁剪（摄像头会短暂重启；数组图块显示“正在应用设置…”）。**关闭**会读取整个传感器图像并**记住您的裁剪设置**——相关字段会持续显示该设置；**开启**则会再次应用该设置。若未设置裁剪区域就开启 ROI，系统将应用一个居中且尺寸减半的裁剪区域（“未设置裁剪区域，因此应用了居中且尺寸减半的裁剪区域。请通过相关字段进行调整。”）。
* **选择**— 在地图上绘制裁剪框：拖动选定范围，或点击两个相对的角（按 Esc 键取消）。矩形会显示在 W/H/X/Y 字段中， 并参照上述步骤进行对齐；在点击**应用**之前不会生效，因此您可以先使用字段箭头进行微调。每次点击**选择**都会生成一个矩形。
* **地图**显示整个传感器上的裁剪区域，因此您可以将其恢复为原始范围：“全传感器，实时”——此时相机正在读取全传感器数据， 或者“来自{时间}的全帧快照。相机仅读取裁剪区域。”（此时相机处于裁剪状态）。如果该阵列此前仅传输过裁剪数据，地图上将显示“尚无全帧视图：该阵列仅传输过裁剪数据。”并附带一个**显示全帧** 按钮，点击该按钮可关闭 ROI。裁剪区域的 `W×H @ X,Y` 标签位于框外（在其上方，或当框触及顶部时位于下方），在地图和实时磁贴上均可见。
* **应用**会提交字段设置：裁剪会启用 ROI；全帧（在**重置** 之后）会将其关闭，同时仍会记住之前的裁剪设置；如果 ROI 处于关闭状态且其字段仍显示已记住的裁剪，则在应用其他更改（格式、像素合并、帧率）时，该 ROI 仍保持关闭状态。
* **对于已对齐的阵列，每个成员的裁剪窗口由对齐结果决定**，因此每台相机都拍摄场景中的同一区域。在对齐之前就已进行裁剪的阵列，将首先基于整个传感器进行对齐（裁剪被暂时取消，完成对齐计算后，再恢复裁剪并生成各相机的独立窗口）。
* 裁剪更改后，自动曝光会针对新的取景范围重新收敛。在裁剪状态下，成员的曝光仍可运行至触发周期结束。
* ROI 的启用/禁用状态以及已保存的裁剪设置将随项目一同保存。
