# 攝影機設定

**攝影機** 標籤頁是 Chloros 用於 LATTICE 攝影機的即時控制介面：主畫面區域會將每台已連接的攝影機以即時磁磚形式顯示，而側邊欄則可在三個頁面之間切換——**攝影機清單**、**設定面板**（可依單一攝影機、陣列或擷取設定分別顯示，每次僅顯示一項）以及**索引計算器**。本頁面詳述了攝影機清單、單一攝影機設定面板及陣列設定面板中的所有控制項。擷取模式、 匯出類型選取，以及「全數擷取」流程，請參閱配套頁面 [擷取設定與模式](capture.md)。

當 Chloros 後端就緒後，「攝影機」分頁便會出現在側邊欄中。以下所有控制項皆透過 `127.0.0.1:5000` 與本地後端進行通訊；除非另有說明，否則變更將立即套用至即時攝影機畫面。

## 本頁使用的攝影機類型

控制項會根據所選攝影機的類型而顯示或隱藏。本手冊全程使用以下術語：

| 術語 | 含義 | 濾鏡通道 |
| --- | --- | --- |
| **RGB 相機** | 配備 FRGB 濾鏡的 LATTICE M3C（型號包含 `-FRGB`） | Red / Green / Blue |
| **拜耳多光譜** | 配備 FRGN、FOCN 或 FNGB 的 LATTICE M3C | FRGN： Red / Green / NIR · FOCN：Orange / Cyan / NIR · FNGB：NIR / Green / Blue |
| **單色 (M3M)** | LATTICE M3M — 一個窄帶濾光片，一個校準波段 | 單波段 |
| **陣列成員** | 作為同步陣列一部分連接的相機（合併或獨立顯示） | 依其濾光片而定 |

 RGB 相機會進行光度處理（白平衡、色彩配置檔、伽瑪校正）；多光譜與單色相機則執行輻射度處理鏈，並跳過光度控制。陣列成員將串流層級的設定（像素格式、解析度、 像素合併、觸發、幀率）設定傳遞給陣列 — 這些欄位在「每台相機」面板中將變為唯讀，並移至陣列設定面板。

### 串流圖塊

每台攝影機都會渲染一個複合式即時圖塊；攝影機還可額外顯示三個灰階 **按通道分割** 的圖塊（參見 [通道分割](#display-overlays-drawn-over-the-live-feed))，而陣列則渲染一個合併圖塊。當前選中的圖塊會顯示一個以該攝影機（或陣列）顏色為底色的選取環。

將游標懸停在圖塊上會顯示 **X** 關閉按鈕：

* 當 **合成** 磁貼的通道分割畫面仍顯示時，關閉該合成磁貼僅會隱藏合成畫面。
* 關閉 **獨立攝影機的最後一個可見磁貼** 會斷開該攝影機的連線。
* **陣列組合成員的分割畫面絕不會斷開** 攝影機連線 — 它們僅會隱藏畫面。

當網格解鎖時，可將任何圖塊拖曳至任意插槽；佈局會隨專案一併儲存。

## 側邊欄 — 攝影機清單

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

第一個側邊欄頁面列出所有已連接的攝影機和陣列：

* **連接攝影機**（綠色）／**連接陣列**（藍色，掃描時顯示「偵測中...」）。當連接對話方塊開啟時，這兩項功能均會停用。
* **擷取全部**（紅色）—— 根據「擷取設定」中選定的匯出類型，擷取清單中的所有攝影機畫面。需開啟專案。 完整說明請參閱 [擷取設定與模式](capture.md)。
* **擷取設定齒輪圖示**（位於「全數擷取」旁）— 開啟 [擷取設定窗格](capture.md#the-capture-settings-pane)。若無專案或正在擷取時，此按鈕將處於停用狀態。

### 攝影機行

每行攝影機顯示一處色彩編碼邊框（該攝影機的自訂顏色）、一個「CAM」標籤——陣列成員會標示藍色 **M**（主）或綠色**S**（從）角色字母 — 以及顯示名稱。預設名稱是 `LATTICE-MODEL (serial)`；可透過每台攝影機的設定窗格重新命名。行按鈕：

| 按鈕 | 效果 |
| --- | --- |
| **眼睛圖示**| 切換可見性。隱藏的攝影機將從網格中移除，並**不包含在「全數擷取」**中。 |
| **齒輪** | 開啟每台攝影機的設定面板（下一節）。 |
| **暫停 / 播放**| 凍結即時預覽**僅限顯示端** — 後端擷取仍會持續運行。暫停的攝影機無法進行擷取。 |
| **X** | 斷開連線。使用者介面會立即更新（樂觀估計）； 後端自行斷開連接可能需要 10–30 秒才能完成。 |

### 陣列行

陣列行會顯示以陣列顏色呈現的「ARRAY」標籤、陣列名稱（可在陣列設定中重新命名），以及一個 **DAQ · 開/關** 按鈕 —— 當陣列層級的光感測器已設定 *或* 任何成員具備單一攝影機感測器時，該按鈕會顯示為 **開啟**； 其工具提示會精確列出哪些感測器對應哪些攝影機。成員攝影機會以縮排形式列於下方，並各自佔有一行。 陣列行按鈕：**眼睛**（同時隱藏／顯示所有成員）、**齒輪**（陣列設定面板）、**X**（斷開整個陣列的連接）。

陣列行及陣列設定面板中顯示的光感測器（DLS）狀態有四種：**關閉**、**等待中**（尚未收到光譜）、**活躍**（過去 3 秒內收到光譜），以及**過期** — 3 秒內未收到新光譜，但最後一次讀數 *仍被使用* （在擷取路徑上，DAQ 讀數永不失效）。

在您重新排序之前，清單會先顯示陣列，接著是獨立相機，而相機（以及每個陣列的成員）則依照 **相機順序** 排列： M3C（拜耳）排在 M3M（單色）之前；在 M3C 之中，依序為 FRGB、FRGN、FOCN，然後是 FNGB； M3M 則依濾光片波長排序，波長最短者排在最前。網格的預設佈局亦遵循相同順序。您可在側邊欄中拖曳獨立相機與整個陣列群組，使其相互交錯以重新排序清單；陣列成員無法獨立拖曳。

點擊相機列上的 **齒輪** 圖示即可開啟。該面板會滑動覆蓋在相機清單上方。

**標題欄**：相機的**顏色樣本**（點擊可開啟原生色彩選擇器 — 用於設定側邊欄邊框及磁磚選取環的顏色）、帶有鉛筆圖示**重新命名**按鈕的**名稱**（若儲存為空名稱，將恢復為預設值 `MODEL (serial)`），以及用於關閉的**×** 按鈕。

### 即時直方圖

窗格頂部顯示一個即時亮度直方圖，該直方圖以約 8 Hz 的頻率根據JPEG 預覽畫面計算得出。其平均值採用拜耳加權法 — (R+2G+B)/4 — 以匹配相機自身的自動曝光（AE）測光。

* **橙色Orange 虛線**= 自動曝光目標。**水平拖曳可重新設定目標** — 放開時會發送一則指令，而拖曳動作會將自動曝光目標模式切換為手動。
* **綠色Green 實線** = 實際平均亮度（自動曝光當前產出的結果）。
* **RGB 按鈕**（右上角）：切換各波段疊加直方圖，其顏色依據相機濾鏡而定（例如在 FRGN 模式下：灰色代表 NIR，綠色代表紅光）。在單色（M3M）相機上，此按鈕標示為「MONO」且處於停用狀態——單色模式始終顯示單波段亮度直方圖。
* X 軸標籤依循當前像素格式的感測器位元深度：0..255、0..1023、0..4095 或 0..65535。

#### 校準標靶表格

此表格僅供 **驗證讀取** 之用（「僅供驗證 — 不修改校準」）。其標題列出相機序列號、濾光片、標靶編號及標記大小（以像素為單位），且每張面板對應一行：

* **面板**，接著每波段一欄，顯示該面板的數值 — 拜耳相機會以名稱和波長顯示其三個波段（例如 FRGN：Red 660 nm / Green 550 nm / NIR 850 nm）；**單色 (M3M) 相機則以名稱顯示其單一波段**（例如 `F750`），且沒有 NDVI 欄位。
* **Sat** — 面板中飽和像素的比例（1% 起顯示為琥珀色，5% 起顯示為紅色）。
* **NDVI 實測**、**NDVI 理論**（面板的參考反射率 NDVI）及 **Δ** —— 僅適用於拜耳多光譜相機。在「NDVI 實測」後的小標記會說明實測 NDVI 是根據什麼計算而來：**ρ**（反射率 —— 有光感測器讀數）、**L**（輻度——無光感測器讀數）或**DN**（相機原始數值）。僅有**ρ** NDVI 可與 NDVI Theo 進行比較：對於 L 和 DN，Δ 欄位將呈灰色且附有說明註記 （「無光感測器讀數：NDVI 源自輻照度，因此 Δ 並非校準檢查」／「NDVI 源自相機原始數值，因此 Δ 並非校準檢查」）。若採用 ρ，當 Δ 值低於 0.02 時顯示為綠色，低於 0.05 時顯示為黃色，其餘情況則顯示為紅色。

### 曝光與增益

<!-- SCREENSHOT-NEEDED: per-camera Exposure & Gain section — Exposure (us) and Gain (dB) rows with Auto/Manual toggles, AE Target Brightness, AE Smoothing slider, AE Region of Interest row with the Aim button, and (on an array camera) AE Tune Speed and Highlight Protection rows. -->

此處所有數值輸入皆採用「長按加速」式旋鈕：輕點 = ±1，長按 >1.5 秒 = ±10，長按 >3 秒 = ±100。鬆開手指時，數值即傳送至相機。

| 控制項 | 範圍／選項 | 預設值 | 適用對象 | 功能說明 |
| --- | --- | --- | --- | --- |
| **曝光 (us)**| 相機的即時最小/最大值 | 自動 | 全部 | 以微秒為單位的曝光時間，附有**自動/手動**切換鈕。自動 = 由攝影機端持續進行自動曝光。若設定為手動曝光，且先前**增益**處於自動模式，則系統會保留自動增益設定，可自由使用攝影機的完整增益範圍，直到您編輯增益或將其設為手動為止。 |
| **增益 (dB)**| 攝影機的即時最小/最大值（例如最高 48 dB） | 手動 （關閉） | 全部 | 類比/數位增益，附有獨立的**自動/手動** 切換鈕。 |
| **AE 目標亮度**| 0–255 | 80，模式**自動**| 全部（當 AE 或自動增益開啟時可編輯） | AE 所瞄準的亮度。在**自動**（預設）模式下，基於直方圖的後端控制器會自行選定目標值，並將曝光維持在感光元件最大值的 60–75 % 之間。輸入數值或拖曳直方圖的橘色線條，即可切換至**手動** 模式。 |
| **AE 平滑度** | 0.5–40，步長 0.1 | 8.0 | 全部 | AE 阻尼。工具提示：「數值越低 = AE 反應越快（在高幀率下可能出現脈動）。數值越高 = 更平滑／更慢。」遠低於預設值的數值可能會導致 AE 出現脈動，並在高幀率下使串流不穩定；8.0 是穩定的預設值。 |
| **AE 感光區域**| 啟用核取方塊 +**瞄準**按鈕 | 關閉 | 全部 | 啟用時，AE 僅對綠色虛線區域進行測量，而非整個畫面。**「瞄準」** 會啟用即時畫面中的「點擊放置」功能：點擊一次會將區域中心定位於畫面 30% 處；點擊並拖曳則可繪製自訂矩形（最小 5% × 5%）。完成一次定位後，「瞄準」功能將自動停用。該區域會根據您設定的任何旋轉/鏡像效果，映射回相機原生座標系，並隨專案一併儲存。 |
| **AE 調校速度** | 0.1–5，步長 0.1 | 1.0 | 僅限陣列成員 | 自動 AE 目標追蹤場景亮度變化的速度；1.0× 每 2.5 秒重新檢查一次。 |
| **高光保護** | 嚴格 (1 %) / 標準 (5 %) / 寬鬆 (15 %) | 嚴格 | 支援此設定的相機 | 在自動曝光使影像變暗之前，畫面中允許有多少比例的高光區域剪切為白色。 |

**拜耳多光譜相機（RGN / OCN / NGB）的照明要求：**場景的三大通道必須均具備足夠光線，否則校準將無法正常運作 — 單次感測器曝光需涵蓋所有三個光譜。請使用 DAQ 光感測器測量光線，或改用全單色模式 (M3M)，讓每個波段皆有獨立的曝光。若擷取畫面違反此要求，Chloros 會偵測到並發出警告（解混限制通知）。 在即時預覽中，當某波段有 25% 或更多像素因解混而遭限制時，該波段的分區圖塊會顯示 **「低可信度波段資料 · N%」**。
{% endhint %}

{% hint style="info" %}
**自動曝光如何分配曝光時間與增益 (1.3.0）。**當增益設為「自動」時，Chloros 會將增益維持在 0 dB，直到曝光時間達到允許的最長值（即 AE 上限、陣列的觸發週期或 DAQ 曝光上限）；此時增益才會上升。在陣列中，觸發率具有優先權：自動曝光會先填滿該觸發率所決定的週期，隨後才提高增益；因此，場景變暗時不再會降低自動觸發率（在 1.2.0 版本中則會）。若陣列成員的 **手動**曝光時間長於觸發週期，則會減慢陣列的觸發速率以配合該曝光時間； 當所有曾導致觸發率減慢的成員皆恢復自動曝光後，自動觸發率才會恢復。當**曝光**與**AE 目標亮度** 均設為「自動」，且 DAQ 光感測器提供讀數時，一旦自動曝光穩定下來，只要測量到的光線值維持在約 ±25 % 範圍內，各攝影機的曝光值便會保持不變； 若發生較大且持續的光線變化、設定重置（例如 ROI 變更）或您手動調整曝光，系統將重新啟動自動曝光。
{% endhint %}

{% hint style="info" %}
**自動曝光的運作方式 (1.3.0)。**

* 手動曝光後，增益將維持在「自動」狀態，直到您變更增益為止。
* 微小的高光不會使場景變暗：佔畫面不超過 1% 的鏡面高光將被忽略；而在已知校準標靶的面板中，則忽略佔單一面板不超過 0.5% 的區域。
* DAQ 曝光上限僅在校準標靶處於視野內時生效；若未偵測到任何面板，相機將根據場景進行曝光。
* 在光線恆定的情況下，曝光值保持穩定；若光線發生大幅變化，則會在數秒內趨於穩定。過曝不再會永久限制曝光值，且當感測範圍 (ROI) 變更時，系統會重新計算曝光值。
* 亮度目標值不會超出相機的，因此光線恢復時不會導致畫面過曝。
* 若相機在強光下自動曝光停止響應，系統會根據光線感測器讀取的當前光照水平（若未連接光線感測器，則依據相機自身的影像幀）維持曝光值， 並在光線變化時恢復正常。即使光線感測器處於黑暗或被遮蔽狀態，也不會干擾此機制。
{% endhint %}

#### ROI 編輯器

1.3.0 版新增功能。ROI 裁切列與其下方的地圖相互配合運作：

* **ROI 開啟 / ROI 關閉**—**立即**啟用或停用感測器裁切（攝影機會短暫重新啟動；陣列磁磚會顯示「正在套用設定…」。）。**關閉**會讀取整個感測器並**記住您的裁切設定**— 欄位會持續顯示該設定；**開啟** 則會再次套用該設定。若在未設定裁切的情況下開啟 ROI，系統會套用一個居中且尺寸減半的裁切區域（「由於未設定裁切，因此套用了居中且尺寸減半的裁切區域。請透過欄位進行調整。」）。
* **選取**— 在地圖上繪製裁切範圍：拖曳選取，或點擊兩個相對的角落（按 Esc 取消）。矩形會顯示在 W/H/X/Y 欄位中， 並對應至上述步驟；在按下**套用**之前不會套用任何設定，因此您可以先使用欄位箭頭進行微調。每次按下**選取** 會產生一個矩形。
* **地圖**會顯示整個感光元件上的裁切範圍，因此您可以將其恢復為原始寬度：「全感光元件，即時」——當相機讀取全感光元件時， 或「來自 {時間} 的全畫幅快照。相機僅讀取裁切區域。」當其處於裁切狀態時。若該陣列過去僅曾串流過裁切影像，地圖將顯示「尚無全畫幅視圖：此陣列僅串流過裁切影像。」並附有**顯示全畫幅** 按鈕，按下後會關閉 ROI。裁切區域的 `W×H @ X,Y` 標籤位於框外（框上方，或當框觸及頂部時位於下方），並同時顯示於地圖及即時磁磚上。
* **套用**會確認當前設定：裁切會啟用 ROI；全畫幅（在**重設** 之後）則會關閉 ROI，同時仍會記住先前的裁切設定；若 ROI 處於關閉狀態，且其畫面仍顯示記憶中的裁切範圍，則在套用其他變更（格式、像素合併、幀率）時，ROI 將保持關閉狀態。
* **對於已對齊的陣列，每個成員的裁切視窗位置由對齊結果決定**，因此每台相機都會框選場景中相同的一塊區域。若陣列在對齊前已進行裁切，系統會先根據完整感光元件進行對齊（裁切會暫時解除，完成對齊運算後，再恢復裁切並設定各相機的視窗）。
* 裁切變更後，自動曝光會針對新的取景範圍重新收斂。在裁切狀態下，成員的曝光仍可持續運行至觸發週期結束。
* ROI 的啟用/停用狀態以及已儲存的裁切設定會隨專案一併保存。

### 對齊（共註冊）

此處同時顯示 **合併陣列與獨立陣列** 的情況（1.2.0 版本僅針對合併陣列顯示）；群組標題為「對齊」。

<!-- SCREENSHOT-NEEDED: array settings Alignment section after a successful calibration — green "RMS x.xx px" residual pill, "✓ All cameras aligned (N)" summary, the per-camera table with px error / match count / NCC columns, the Recalibrate alignment button and the "Auto-expose cameras for alignment" checkbox. -->



* **殘差** 資訊框：「RMS x.xx px」—— 小於 1 px 時為綠色，小於 3 px 時為琥珀色，否則為紅色，或若有任何攝影機失敗時亦為紅色；首次求解前顯示「無配置檔」。
* 摘要行：「✓ 所有相機均已對齊 (N)」／「⚠ p/N 台相機已對齊 — <serial (filter)="">失敗」／「裁切功能啟用 — 重新校準以進行對齊（使用完整感光元件）」 / 「等待曝光穩定中……」 / 「套用設定中……」 (相機正在重新啟動) / 「陣列停止傳送影像幀 — 請重新連接陣列」。
* 每台相機資料表：相機（序號後 4 位 + 濾鏡）、以 px 為單位的重新投影誤差及匹配次數（主相機顯示為「ref」），以及相對於 0.35 通過門檻的重疊正規化交叉相關分數。
* **重新校準對齊** 按鈕（在第一個配置檔之前顯示「校準對齊」）—— 針對新幀重新執行共註冊。
* **「自動曝光相機以進行對齊」** 核取方塊（預設為勾選）—— 暫時提高曝光不足或平淡的相機亮度（先調整曝光，再調整增益），使其具備可供比對的紋理，隨後恢復自動曝光。

Chloros 在連接後，無論處於何種顯示模式，都會在陣列成員的自動曝光穩定後自動對齊每個陣列（系統會持續嘗試長達 5 分鐘）；合併預覽畫面在開啟時也會進行對齊。 獨立陣列沒有合成圖塊，因此本節會輪詢對齊狀態並自行執行「重新校準」。若焦點或場景深度發生變化，則執行重新校準。對齊功能**設計上僅限當前工作階段** — 它絕不會儲存至設定檔中，因為其取決於當下的場景距離。擷取的影像仍可以像素對齊的方式匯出 （參見 [對齊後匯出](capture.md#per-array-controls)）。

### 智慧暗角

* **啟用校正**核取方塊 — 將各相機的暗角估算值套用至輻射測量鏈（即時**及** 匯出）。
* **從當前視圖校準**— 請先將陣列對準均勻目標（平面面板、牆壁或天空）；每台相機將分別進行平坦化處理，狀態報告會顯示「n/N 台相機 · −x.x %」的平坦度提升值。**清除** 會移除該估算值。
* 狀態：「已校正」、「未校正」，或「部分校正 — 請重新執行」（當僅有部分鏡頭的估算值在當前取景範圍內仍適用時，例如在「重新校正」操作後，某鏡頭的裁切視窗位置已變更）——請再次執行「校正」。
* 請透過 [即時預覽](#live-preview) 中的每台相機專用 **暗角** 滑桿，針對每台相機進行微調。

### 即時預覽

* **直方圖**核取方塊 + 寬度滑桿（佔畫面 0.10–0.90）—— 同時在每個成員的圖塊上顯示直方圖條（包含分色通道圖塊），以及針對整個陣列設定的每台相機 [直方圖疊加層](#display-overlays-drawn-over-the-live-feed) 設定。當每個成員皆已啟用此功能時，此處會顯示為開啟狀態。若在**獨立** 陣列中，此為該群組中唯一的一行。
* *僅限合併模式：* **索引**：勾選方塊 + 齒輪圖示 — 開啟共享的 [索引計算器](#index-calculator-pane)，其中繪製來自**所有** 成員攝影機的區間帶。下方的一行表達式預覽欄會顯示當前表達式（「未設定表達式 — 開啟計算器以建立一個」），並每秒刷新一次。
* *僅限合併模式：* **渲染解析度**下拉選單（預設值與單一攝影機模式相同，預設為 720p）：包含即時預覽串流的高度**以及** 儲存的合成輸出尺寸。請注意面板中的說明：「預覽 + 儲存的合成尺寸。單一攝影機影像始終以全解析度輸出。」

## 單一相機設定 vs 陣列管理設定

當相機為陣列成員時，各項設定位置的快速參考：

| 由陣列管理（在相機面板中為唯讀） | 陣列內仍為單一相機設定 |
| --- | --- |
| 像素格式、解析度、像素合併 | 自動曝光（曝光、增益、目標值、平滑、ROI） |
| 觸發模式／來源、幀率 | 降噪、銳利度、 暗角 |
| | 方向（鏡像/旋轉）、顯示疊加層（陣列設定 → 「即時預覽」可同時在每個成員上設定直方圖）、點測光 |
| | 索引（獨立顯示陣列）、光感測器綁定 |

其他跨模組行為：

* **合併顯示與獨立顯示** 於陣列連接時選擇：合併 = 一個對齊的複合圖塊（成員僅透過「分割視圖」傳輸影像）；獨立 = 每個成員渲染各自同步的圖塊。相機絕不會同時顯示獨立影像流與陣列圖塊。
* ****自動重新連線**：開啟已儲存的專案時，系統會還原其中的攝影機與陣列，並在串流恢復前將所有已儲存的設定重新套用至後端。
* **擷取閘控**：隱藏或暫停的攝影機將不包含在「全數擷取」中；陣列僅在所有成員皆處於隱藏／暫停狀態時才會被完全封鎖。 請參閱 [擷取設定與模式](capture.md)。

## 設定的儲存方式

「攝影機」分頁的狀態會 **與專案一同** 儲存，而非儲存在瀏覽器中：

* 每次反應式變更都會將攝影機和陣列的當前狀態快照儲存至專案的 `cameras.json`（經過 500 毫秒去抖動處理）。這包含相機名稱與顏色、曝光/增益/自動曝光設定、像素格式/解析度/像素合併、觸發率、預覽設定（渲染解析度、降噪、銳利度、暗角、色彩配置檔、高光、飽和度/對比度）、方向、疊加層、通道分割、索引配置、預測式自動曝光設定、自動曝光 ROI、 陣列名稱、顯示模式、陣列擷取設定（包含 ROI 裁切、ROI 是否啟用，以及 ROI 關閉時所儲存的裁切設定）、陣列的線路預算，以及網格區塊（餵送縮放、檢視模式、網格鎖定、手動磁磚順序、隱藏攝影機、關閉磁磚、活躍攝影機）。
* 光感測器綁定設定儲存於專案的 `sensors.json` 檔案中。
