# 摄像机设置

“**摄像机**”选项卡是 Chloros 用于 LATTICE 摄像机的实时控制界面：主画面区域以实时磁贴的形式显示所有已连接的摄像机，侧边栏可在三个页面之间切换——**摄像机列表**、**设置面板**（单个摄像机、阵列或捕获设置——每次仅显示一种）以及**索引计算器**。本页面详细说明了摄像机列表、单个摄像机设置面板和阵列设置面板中的所有控件。 采集模式、导出类型选择以及“全量采集”流程请参见配套页面 [采集设置与模式](capture.md)。

当 Chloros 后端就绪后，“摄像头”选项卡将出现在侧边栏中。以下所有控件均通过 `127.0.0.1:5000` 与本地后端通信；除非另有说明，否则更改将立即应用于实时摄像头。

## 本页使用的摄像头类型

控件会根据所选相机的类型自动显示或隐藏。本手册通篇使用以下术语：

| 术语 | 含义 | 滤光片通道 |
| --- | --- | --- |
| **RGB 相机** | 配备 FRGB 滤光片的 LATTICE M3C（型号中包含 `-FRGB`） | Red / Green / Blue |
| **拜耳多光谱** | 配备 FRGN、FOCN 或 FNGB 的 LATTICE M3C | FRGN：Red / Green / NIR · FOCN：Orange / Cyan / NIR · FNGB：NIR / Green / Blue |
| **单波段 (M3M)** | LATTICE M3M — 一个窄带滤光片，一个校准波段 | 单波段 |
| **阵列成员** | 作为同步阵列的一部分连接的相机（组合或独立显示） | 按其滤光片 |

RGB 相机将进行光度处理（白平衡、色彩配置文件、伽马校正）；多光谱和单光谱相机将执行辐射测量链处理，并跳过光度控制。 阵列成员将流级设置（像素格式、分辨率、像素合并、触发、帧率）提交至阵列——这些行在“每台相机”面板中将变为只读，并移至阵列设置面板。

### 视频流磁贴

每台摄像机渲染一个复合实时图块；摄像机还可额外显示三个灰度 **按通道分割** 的图块（参见 [通道分割](#display-overlays-drawn-over-the-live-feed)），而数组则渲染一个组合图块。活动图块上带有摄像机 （或数组）的颜色显示一个选中环。

将鼠标悬停在磁贴上会显示一个 **X** 关闭按钮：

* 当其通道分割磁贴仍存在时关闭 **合成** 磁贴，仅会隐藏该合成磁贴。
* 关闭 **独立摄像头的最后一个可见磁贴** 会断开该摄像头的连接。
* **组合数组中的成员分割图块绝不会断开** 摄像机连接——它们只会隐藏。

解锁网格后，可将任意图块拖动到任意插槽；布局将随项目一起保存。

## 侧边栏 — 摄像机列表

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

第一个侧边栏页面列出了所有已连接的摄像机和阵列：

* **连接摄像机**（绿色） /**连接阵列**（蓝色，扫描时显示“检测中...”）。当连接对话框打开时，这两个选项均不可用。
* **捕获全部**（红色）——使用“捕获设置”中选择的导出类型，捕获列表中的所有摄像机。需要打开一个项目。详细说明请参见 [捕获设置与模式](capture.md) 中有详细说明。
* **捕获设置齿轮图标**（位于“全部捕获”旁边）—— 打开 [捕获设置窗格](capture.md#the-capture-settings-pane)。若未打开项目或正在捕获时，该按钮将禁用。

### 摄像机行

每行摄像机显示一条彩色边框（摄像机的自定义颜色）、一个“CAM”标签——带有蓝色 **M**（主）或绿色**S** （从属）角色字母——以及显示名称。默认名称为 `LATTICE-MODEL (serial)`；可在“每台摄像机设置”面板中重命名。行按钮：

| 按钮 | 效果 |
| --- | --- |
| **眼睛图标**| 切换可见性。隐藏的摄像头将从网格中移除，并**不包含在“全景捕获”**中。 |
| **齿轮图标** | 打开单个摄像头的设置面板（下一节）。 |
| **暂停 / 播放**|**仅在显示端**冻结实时预览——后端抓取仍会继续运行。暂停的摄像头无法进行捕获。 |
| **X** | 断开连接。 界面会立即更新（乐观估计）；后端断开连接本身可能需要 10–30 秒才能完成。 |

### 数组行

数组行会显示一个以数组颜色为底色的“ARRAY”标识、数组名称（可在数组设置中重命名）以及一个 **DAQ · 开/关** 按钮——当数组级光线传感器已启用 *或* 任何成员拥有单摄像头传感器时，该按钮显示为 **开**；其工具提示会精确列出哪个传感器向哪个设备传输数据。 成员摄像头以缩进形式列在下方，各自占据一行。数组行按钮：**眼睛图标**（批量隐藏/显示所有成员）、**齿轮图标**（数组设置面板）、**X**（断开整个数组的连接）。

数组行和数组设置面板中使用的光传感器（DLS）状态有四种：**关闭**、**等待**（尚未收到光谱）、**活动**（最近 3 秒内收到光谱）以及**过期** —— 3 秒内未收到新光谱，但最后一次读数*仍在使用中*（捕获路径上的数据采集读数永不过期）。

您可以在侧边栏中将独立相机和整个阵列组相互拖拽以重新排序；阵列成员无法单独拖动。

## 单相机设置面板

点击相机行上的 **齿轮** 图标打开。该面板会滑动覆盖在相机列表上。

<!-- SCREENSHOT-NEEDED: per-camera settings pane, top portion — header with color swatch, camera name, rename pencil and close X; live histogram with the orange dashed AE-target line and green mean-luma line; the RGB per-band toggle button visible top-right of the histogram. -->

**标题栏**：摄像机的**颜色样本**（点击可打开原生颜色选择器——用于设置侧边栏边框和图块选择环的颜色）、带有铅笔图标**重命名**按钮的**名称**（保存为空名称将恢复为默认值 `MODEL (serial)`），以及**×** 用于关闭。

### 实时直方图

面板顶部显示的实时亮度直方图，基于 JPEG 预览图像以约 8 Hz 的频率计算得出。其均值为拜耳加权值 — (R+2G+B)/4 ——以匹配相机自身的自动曝光测光。

* **Orange 虚线**= 自动曝光（AE）目标值。**水平拖动可重新设定目标值** — 松开鼠标时会发送一条命令，且拖动操作会将自动曝光目标模式切换为“手动”。
* **Green 实线** = 实际平均亮度（即当前自动曝光的输出值）。
* **RGB 按钮**（右上角）：切换按波段显示的叠加直方图，其颜色由相机的滤镜决定（例如在 FRGN 模式下：灰色 NIR、绿色、红色）。 在单色（M3M）相机上，该按钮显示为“MONO”且处于禁用状态——单色模式始终显示单波段亮度直方图。
* X 轴标签遵循当前像素格式的传感器位深度：0..255、0..1023、0..4095 或 0..65535。

### 曝光与增益

<!-- SCREENSHOT-NEEDED: per-camera Exposure & Gain section — Exposure (us) and Gain (dB) rows with Auto/Manual toggles, AE Target Brightness, AE Smoothing slider, AE Region of Interest row with the Aim button, and (on an array camera) AE Tune Speed and Highlight Protection rows. -->

此处所有数值输入均采用“长按加速”式旋转控件：轻点 = ±1，长按 &gt;1.5 秒 = ±10，长按 &gt;3 秒 = ±100。松开手指时，数值将发送至相机。

| 控制项 | 范围/选项 | 默认值 | 适用对象 | 功能说明 |
| --- | --- | --- | --- | --- |
| **曝光时间 (us)**| 摄像头的实时最小/最大值 | 自动 | 全部 | 以微秒为单位的曝光时间，带有一个**自动/手动** 切换开关。自动 = 摄像端持续自动曝光。 |
| **增益 (dB)**| 摄像头的实时最小/最大值（例如最高 48 dB） | 手动（关闭） | 全部 | 模拟/数字增益，带有独立的**自动/手动** 切换开关。 |
| **自动曝光目标亮度**| 0–255 | 80，模式为**自动**| 全部（当自动曝光或自动增益开启时可编辑） | 自动曝光（AE）的目标亮度。在**自动**模式（默认）下，基于直方图的后端控制器会自行选择目标值，将曝光保持在传感器最大亮度的 60–75 % 之间。 输入数值或拖动直方图的橙色线可将其切换为**手动** 模式。|
| **AE 平滑度** | 0.5–40，步长 0.1 | 8.0 | 全部 | AE 平滑度。工具提示：“数值越低，AE 响应越快（高帧率下可能出现脉冲）；数值越高，响应越平滑/越慢。”远低于默认值的数值可能导致 AE 出现脉冲，并在高帧率下导致流媒体不稳定； 8.0 是稳定的默认值。 |
| **AE 关注区域**| 启用复选框 +**瞄准**按钮 | 关闭 | 全部 | 启用后，AE仅对绿色虚线区域进行测量，而非整个画面。**瞄准**按钮可激活实时画面中的“点击放置”功能：单击将区域居中放置于画面30%处；点击并拖动可绘制自定义矩形 （最小 5% × 5%）。“瞄准”功能在放置一次后自动失效。该区域会根据您设定的任何旋转/镜像效果映射回摄像机原生坐标系，并随项目一起保存。 |
| **AE 调速** | 0.1–5，步长 0.1 | 1.0 | 仅限数组成员 | 自动 AE 目标追踪场景亮度变化的速度；1.0× 表示每 2.5 秒重新检查一次。 |
| **高光保护** | 严格 (1 %) / 正常 (5 %) / 宽松 (15 %) | 严格 | 支持此设置的相机 | 在自动曝光使图像变暗之前，画面中允许出现多少比例的白色剪切区域。 |

{% hint style="info" %}
**拜耳多光谱相机的光照要求（RGN / OCN / NGB）：** 场景的三个通道都必须有足够的光线，否则校准无法正常工作——单次传感器曝光覆盖所有三个光谱。请使用 DAQ 光传感器测量光照，或切换至全单色模式 （M3M）模式，确保每个波段获得独立曝光。若捕获数据违反此要求，Chloros将检测到并发出警告（“unmix-clamp”通知）。
{% endhint %}

### 实时预览

本节中的所有设置均为 **仅显示端**—— 它们会改变实时流中的显示效果，而保存的截图仍保持线性且未被修改 —— 只有一个例外：**暗角** 具有辐射计量特性，也会影响导出文件（下文将详细说明）。

| 控制项 | 范围/选项 | 默认值 | 适用对象 | 功能说明 |
| --- | --- | --- | --- | --- |
| **渲染分辨率** | 360p（最快） / 480p / 720p / 1080p / 原生传感器分辨率（最慢） | 720p | 全部 | 后端运行辐射度预览链时采用的高度。降低该值可在不改变视场角的情况下提升帧率。 |
| **指数**| 启用复选框 + 齿轮图标 | 关闭 | 仅限拜耳多光谱传感器，**不**适用于组合阵列传感器 | 实时植被指数预览。 点击齿轮图标可打开共享的 [指数计算器](#index-calculator-pane)，其中预加载了相机的滤光片自然波段（例如 `Red_660_RGN`、`Green_550_RGN`、`NIR_850_RGN`）。 自定义表达式加 LUT（开/关，级别默认值为 3，最小默认值为 0.2，最大默认值为 1）会在每个预览帧上进行计算。组合阵列成员会隐藏此行——该阵列拥有一个共享指数。 |

| **伽马** | 开 / 关 | 开 | 仅限 RGB | 在实时预览中显示伽马（γ = 2.2 LUT）。 已保存的捕获数据保持线性。 |

### 预测性自动曝光（DLS驱动）

此部分仅在**连接了至少一个DAQ光传感器**时才会显示——求解器需要实时下行光谱来驱动该功能。

<!-- SCREENSHOT-NEEDED: Predictive Auto-Exposure (DLS-driven) section with a DAQ connected — Enable checkbox, Smoothing (α) slider at 0.30, and the "Recalibrate ρ" button. -->

| 控制 | 范围 | 默认 | 功能说明 |
| --- | --- | --- | --- |
| **启用** | 复选框 | 开启 (独立相机) | 闭式求解器利用 DLS 光谱及相机的校准包标量，将最亮波段调整至接近饱和，同时确保最暗波段高于信噪比下限 —— 每次求解仅写入一次曝光数据，无需稳定循环。专为太阳能供电的延时摄影设计，此类场景中每张照片都必须曝光正确。 当 DLS 读数过时/缺失或未加载校准包时，后端会自动回退到反应式自动曝光模式。|
| **平滑度 (α)** | 0.05–1.0，步长 0.05 | 0.3 | 对连续预测解进行平滑处理（数值越低，平滑效果越强）。 |

{% hint style="info" %}
**数组连接默认会关闭预测性自动曝光** — 对于数组，Chloros的智能自动曝光加上相机端的自动曝光功能（带饱和度保护）来控制曝光，而预测式自动曝光的单一场景反射率估计值在混合场景中并不安全。如果您特别需要 DLS 驱动的辐射度曝光，可在此为每台相机单独重新启用该功能。
{% endhint %}

**DAQ驱动的曝光上限和入射锁定自动曝光。**无论上述复选框是否勾选，当 DAQ 光传感器被分配给 RGB 相机时，Chloros 会根据测得的绝对向下辐照度 ——计算出能使 100% 反射率表面保持在剪切阈值以下的最大曝光×增益值，并将其作为自动曝光的**上限**应用。 当上限生效时，相机处于**入射光锁定**状态：它以入射光测得的曝光值进行开环运行，增益设为0 dB——曝光值跟随测得的光照，而非场景内容。 由于上限值只能缩短曝光时间，因此其本身不会导致过曝。当数据采集（DAQ）读数缺失、过时（&gt;30 秒）、过暗，或者在锁定曝光下≥15%的画面区域发生过曝 （即传感器与相机所测得的照度不同）。此功能无图形界面开关；当 RGB 相机绑定有 DAQ 时，这始终是标准行为。

其他跨模块行为：

* **合并显示与独立显示** 在连接阵列时选择：合并 = 一个对齐的合成图块（成员仅通过“分屏视图”传输画面）；独立 = 每个成员渲染自己的同步图块。一台相机绝不会同时显示独立画面和阵列图块。
* **自动重新连接**：打开已保存的项目将恢复其摄像机和阵列，并在流恢复之前将所有已保存的设置重新应用到后端。
* **捕获门控**：隐藏或暂停的摄像机不会被纳入“全景捕获”；只有当所有成员均处于隐藏/暂停状态时，数组才会被完全屏蔽。参见 [捕获设置与模式](capture.md)。

## 设置的持久化方式

“相机”选项卡的状态是**随项目**保存的，而非保存在浏览器中：

* 每次响应式更改都会将相机和阵列的状态快照保存到项目的 `cameras.json` 中（经过 500 毫秒的防抖处理）。这包括相机名称和颜色、曝光/增益/自动曝光设置、像素格式/分辨率/像素合并、触发率、预览设置（渲染分辨率、降噪、锐度、暗角、色彩配置文件、饱和度/对比度）、方向、叠加层、通道分割、索引配置、预测性自动曝光设置、 AE ROI、阵列名称、显示模式、阵列捕获设置（包括 ROI 裁剪位置）以及网格块（馈送缩放、视图模式、网格锁定、手动拼图顺序、隐藏摄像机、关闭的拼图、活动摄像机）。
* 光传感器绑定信息保存在项目的 `sensors.json` 中。
* 重新打开项目将重新连接硬件并重新应用所有设置。
* **未打开项目 = 仅限会话**：若未打开项目，关闭 Chloros 后所有设置均不会保留。
* 无论是否存在项目，以下内容均为仅会话有效：暂停状态、点测光样本、各摄像头的“校准目标”复选框（默认关闭）以及阵列对齐配置文件（按设计在每次会话中重新计算）。
* 唯一例外：****“采集设置”**的导出选项和采集模式将按项目保存在本地应用存储中，而非 `cameras.json` —— 参见 [采集设置与模式](capture.md)。</array></camera></serial>
