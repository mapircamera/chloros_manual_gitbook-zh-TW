# 蓋板規格與校準範圍

> 關於遮光罩本身——哪些遮光罩與哪些感測器搭配使用、其安裝方式以及光學特性——均詳載於 **[DAQ 使用手冊](https://mapir.gitbook.io/daq)** 中。本頁說明如何向 Chloros
*宣告* 已安裝的遮光罩，這正是確保校正準確的關鍵。

每顆 DAQ 光感測器的出廠輻測校準，所描述的皆為 *裸露* 狀態下的感測器。安裝在漫射器外層的實體蓋板會改變感測器所收集的光線，因此 Chloros
會將出廠測量所得的 **蓋板校正曲線** 套用至校準套件之上。 宣告正確的蓋子是獲得校準數據的關鍵環節——本頁說明各型號可用的蓋子種類、宣告方式，以及感測器實際的校準光譜範圍。

## 各型號的蓋板可用性

| 蓋板配置檔 (`cap_id`) | 實體蓋板 | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | 陽光餘弦校正蓋 (**所有機型預設配備**) | 是 | 是 | 是 |
| `fov_15` / `fov_45` / `fov_90` | 視野限制錐（15° / 45° / 90°） | 是 | — | 是 |
| `fov_30` / `fov_60` | 視野限制錐（30° / 60°） | 是 | — | — |
| `none` | 未安裝蓋帽 | — | — | 是 |

型號特定說明：

* **DAQ-M 僅有一種蓋帽型號：`sunshine_cosine`。** 其產品定義為「裸機加 Sunshine 蓋」，而裸機版 DAQ-M 無需幾何輪廓。
* **裸機版 DAQ-U 屬於真正的「裸機」** — 它完全不需要幾何輪廓，因此不存在對應的 `none` 輪廓。
* **DAQ-E 上的 `none` 並非無操作（no-op）。** DAQ-E 的內嵌式、玻璃覆蓋擴散器本身具有實際的幾何校正，因此「無遮光罩」在該型號上本身即為一個已測量的輪廓。
* **未加裝遮光蓋的 DAQ-E 無法測量任何高度角的直射陽光** —— 陽光遮光蓋是現場配置的必要組件。請勿規劃使用未加裝遮光蓋的 DAQ-E 進行戶外作業。

在 GUI 的「每感測器設定」中（「光感測器」分頁內的齒輪圖示），**遮光罩** 下拉選單在 DAQ-U 和 DAQ-M 上亦提供「無（裸感測器）」選項——根據上述說明，在這兩款機型上，「裸感測器」僅表示未套用遮光罩校正。 僅在物理上移除遮光蓋時才應選擇此選項。

## 指定遮光蓋 — 及其重要性

**所指定的 `cap_id` 必須與感測器上實際安裝的遮光蓋相符。** 無論是感測器還是軟體，均無法偵測已安裝的蓋子。此宣告會驅動兩項功能：

1. 套用至每個光譜的 **即時校正**。
2. 寫入每個 `.daq` 記錄中的 **蓋子標記**，後續的反射率處理會以此為依據。

Sunshine 蓋帽的設計衰減係數約為 **12×**，因此若宣告的蓋帽型號錯誤，所記錄的光譜會因此產生約此倍數的誤差。請立即宣告蓋帽變更。

### 設定蓋帽

GUI：[光感測器] 索引標籤 → 感測器行上的齒輪圖示 → **蓋帽** 下拉式選單。 所有機型的預設值皆為 `sunshine_cosine`，此為預設假設（DAQ-U、DAQ-M 及 DAQ-E 出廠時未配備蓋帽，且記錄會顯示系統預設使用蓋帽，直到您選擇其他選項為止），此設定將隨專案保留。



CLI<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->
（後端必須正在運行）：

```bash
# Declare at connect time
chloros-cli daq pool-connect --eth-host daq-e-def330.local --cap-id sunshine_cosine

# Swap at runtime (after physically changing the cap)
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id fov_45
```

CLI
在語法上接受完整的 `cap_id` 清單（例如 `{none, fov_15, fov_30, fov_45, fov_60, fov_90, sunshine_cosine}`）； 每個設定檔會在連線時根據感測器模型進行驗證，因此若傳入不可用的 cap ID（例如在 DAQ-U 上使用僅限 E 型的 ID），系統會明確顯示錯誤並失敗，而非進行錯誤的校正。若未傳入任何參數，後端預設值為 `sunshine_cosine`。

Python
SDK
：請在連線時使用 `connect_daq_sensor(cap_id="sunshine_cosine")` 為 cap 命名，或於執行時使用 `DAQSensorSession.set_cap("fov_45")` 進行替換；詳見 [SDK
參考手冊](../reference/sdk-reference.md#daq-sensor-sessions)。

進階：預設設定檔隨 Chloros
安裝包內建於 `daq/cap_profiles/<u|m|e>/<cap_id>.json`，並可由使用者透過 `~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json` 進行覆寫。

除了上限設定外，從未重新校準過的感測器會自動獲得一項源自機隊數據的小幅暗偏移精修——無需使用者介入。

## DAQ-E-S：固定擴散板與傾斜角度

**DAQ-E-S** 是一款 DAQ-E，但有兩項對 Chloros
至關重要的差異。其餘所有功能（發現、連接、PTP、記錄、裝置設定）皆與 DAQ-E 完全相同。

* **其漫射器為固定式，因此無需進行頂蓋校正。** 該擴散片在進行工廠校準測量時已安裝於裝置上，因此該校準值已準確反映真實的向下輻照度。無論系統如何要求，Chloros
均不會對其套用任何上限曲線：以該裝置命名的上限曲線會被忽略並顯示提示訊息；其記錄資料會顯示上限曲線源自模型；且針對該裝置，系統絕不會觸發「假設上限」警告。 在「專案設定」→「DAQ 光感測器」中，其資料列顯示無上限值，且全專案範圍的上限值覆寫設定亦不適用於此感測器。請勿手動對其資料套用上限值：否則，其上的「日照校正」數值將被高估約 11 倍。
* **此感測器配備三軸加速度計。** 該擴散器的餘弦響應僅在水平狀態下有效，因此傾斜的感測器會報告錯誤的輻照度，且無其他異常徵兆。因此，每個 DAQ-E-S 讀數都包含其傾斜、滾轉和俯仰角度，而從其中一個感測器記錄的 `.daq` 檔案，會將這些數據儲存於每個光譜旁 (`imu_tilt_deg`、`imu_roll_deg`、`imu_pitch_deg`、……) 旁一併儲存，因此您可以區分雲層與赤道儀座架晃動的情況。

有關每個姿態欄位以及姿態資料流中故障的通報方式，請參閱 [CLI
參考手冊中的 DAQ-E-S](../reference/cli-reference.md#daq-e-s--fixed-diffuser-and-tilt-sensor)。

## 陽光遮光罩效能（戶外配置）

可用於制定程序的數值：

| 屬性 | 值 |
| --- | --- |
| 視野 | 180° 半球形 |
| 餘弦響應誤差 | 入射角達 60° 時 ≤ ±4 %；達 70° 時 ≤ ±4.5 % |
| 低日照角限制 | 不建議在太陽高度角低於 ~15° 時使用 |
| 衰減 | ~12×（設計值） |
| 遮光罩重新安裝重複性 | ≈ 1.5 % |
| 定量輻照度 | 取**≥ 15 秒**的平均讀數（儀器特性，非缺陷） |

對於任何定量輻照度數值（包含反射率參考值），請採用至少 15 秒讀數的平均值，而非單一幀數據。

## 經校準的光譜範圍

| 屬性 | 值 |
| --- | --- |
| 光譜採樣 | 340–1010 nm，步長 5 nm（135 個點） |
| 輻測校準範圍 | **~374–974 nm**（由軟體強制執行） |

感測器會回報完整的 340–1010 nm 網格數據，但可追溯至 NIST 的輻測增益範圍僅涵蓋 ~374–974 nm。 對於任何光譜權重有少於一半位於該範圍內的相機波段，Chloros
**會拒絕進行絕對反射率分割**，並回報跳過原因 `dls-uncalibrated-band-<nm>`，而非產生未經校正的結果。 在現有上市的相機型號中，僅有 F988 濾鏡超出此範圍；該型號改採反射率面板工作流程 — 請參閱 [反射率工作流程](reflectance.md)。

有關感測器型號、傳輸方式及感測器 ID，請參閱 [DAQ 概述](README.md)。關於處理過程中如何消耗上限標記，請參閱 [記錄與 .daq 格式](recording.md)。
