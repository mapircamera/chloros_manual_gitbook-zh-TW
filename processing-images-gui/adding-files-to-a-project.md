# 將檔案新增至專案

在 Chloros 中建立或開啟專案後，下一步便是新增多光譜影像以開始處理。透過「檔案瀏覽器」<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">分頁，您可以輕鬆匯入影像並管理資料集。

## 開啟檔案瀏覽器

1. 在 Chloros 中開啟或建立專案
2. 點擊左側邊欄中的 **檔案瀏覽器** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 圖示
3. 「檔案瀏覽器」面板將顯示您專案的檔案清單

{% hint style="info" %}
**支援的檔案類型**：

* **Survey3W / Survey3N**：RAW+JPG 配對檔及 JPG 影像 （建議使用 RAW+JPG）
* **LATTICE**：`.tif` / `.tiff` 擷取檔 — 由 Chloros 相機控制程式或 LATTICE 集線器所記錄
* **光感測器資料**：`.daq` 記錄檔（DAQ-U/M/E）及 DAQ-M `.csv` 下行輻射日誌 — 需與影像一併匯入以進行反射率校正
{% endhint %}

***

## 將影像新增至您的專案

有兩種主要方式可將影像新增至您的專案：

### 方法 1：新增檔案

使用此選項可匯入單一影像檔案或少量選取的檔案。

1. 點擊「檔案瀏覽器」面板頂端的 **「新增檔案」** <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> 按鈕
2. 導航至包含影像的資料夾
3. 選取一個或多個影像檔案（按住 **Ctrl** 鍵可選取多個檔案）
4. 點擊 **「開啟」** 以匯入選取的檔案

### 方法 2：新增資料夾

使用此選項可一次匯入資料夾中的所有圖片。您可以在同一個對話方塊中選取 **多個資料夾**。

1. 點擊檔案瀏覽器面板頂部的 **「新增資料夾」** <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> 按鈕
2. 導航至並選取包含您的擷取 session 圖片的資料夾
3. 點擊 **「選取資料夾」** 以匯入所有受支援的圖片

{% hint style="info" %}
**系統會報告無法載入的檔案。** 若某個資料夾包含 Chloros 能識別但無法載入的檔案，系統會顯示警告訊息告知您 — 影像不會在網格中悄然消失。
{% endhint %}

***

## 匯入 LATTICE 擷取資料夾

LATTICE 擷取資料會以 **每個匯出層級對應一個子資料夾** 的方式儲存 — 例如 `raw/`、`debayered/`、 `radiance/`、`reflectance/`、`preview/` — 根目錄中則有對應的 `.daq` 下行資料檔案：

```
output/
├── raw/           capture_<timestamp>_SN<serial>_raw.tif
├── debayered/     capture_<timestamp>_SN<serial>_debayered.tif
├── preview/       capture_<timestamp>_SN<serial>_display.tif
└── *.daq          the downwelling reading matched to the capture
```

**請將「新增資料夾」指向擷取檔的根目錄**（即上方的 `output/`）。 當選取的資料夾本身不含影像，但含有子資料夾時，Chloros 會自動深入這些子資料夾 — 該層級的子資料夾以及根目錄中的 `.daq` 都會一次全部被擷取。**擷取檔的匯入方式：*** 每個擷取檔會以 **單一影像** 的形式匯入，並按擷取檔分組（而非每層級各佔一筆）。同一擷取檔的其他層級會以該影像的檢視模式呈現。
* **處理流程始終從原始幀開始。** 其他層級雖可檢視，但僅有 `raw` 會被送入處理流程 — 重新處理已處理過的產品會導致校正效果重複套用，因此 Chloros 會拒絕此操作。 重新匯入的匯出檔絕不會佔用擷取的原始檔槽位。
* **未**包含原始檔的擷取資料夾可正常匯入並顯示，但處理過程會跳過該資料夾，並在日誌中標註此情況。 （CLI 參數 `--input-level` 可強制指定此情況的入口點 — 請參閱 [CLI 參考手冊](../reference/cli-reference.md#what-a-captures-folder-looks-like)。）
* 自 1.3.0 版本起，擷取資料夾亦可包含 `clamp_masks/` 資料夾（用於輻照度與反射率層級的逐像素遮罩 — 請參閱 [輸出影像格式](../output-image-formats.md#clamp-masks)）。 遮罩並非場景的影像，且 Chloros 在匯入時會跳過這些遮罩，無論它們位於何處。

**LATTICE hub 工作階段** 的匯入方式相同： 在「新增資料夾」中選取從 hub 複製而來的工作階段資料夾（其中包含 `raw/` 以及 `previews/`），並一併選取任何 DAQ-M `.csv` 下行輻射日誌。 若您的電腦尚未快取相機或 DAQ 的校準資料，Chloros 會在匯入時根據序號自動擷取（需連線至網際網路一次）。***

## 了解檔案瀏覽器表格

影像匯入後，會顯示於包含以下欄位的表格中：

### 檔案名稱

* 來自相機的原始檔案名稱
* 維持相機的命名規則（例如：IMG\_0001.RAW 或 capture\_20260816\_101500\_SN213800234\_raw.tif）

### 時間戳記

* 影像拍攝的日期與時間
* 從影像的 EXIF 元資料中擷取
* 用於光感測器配對、PPK 同步及校準標靶排程

### 相機型號

* 自動偵測的相機與濾鏡配置
* Survey3 範例：Survey3W_RGN、Survey3N_OCN、Survey3W_RGB
* LATTICE 範例：LATT-M3M-L41-F550、LATT-M3C-L87-FRGN
* 用於套用正確的處理設定檔

### 標靶欄位（核取方塊）

* 若影像中包含校準標靶，請勾選此方塊
* 當至少勾選一張影像時，系統將**僅掃描已勾選的影像**以搜尋標靶
* 詳情請參閱 [選擇標靶影像](choosing-target-images.md)

### 檢視影像元資料

點擊表格上方右上角的切換按鈕，即可在影像網格區域中顯示所選影像的元資料。

## 專案中的光感測器檔案

* `.daq` 和 `.csv` 檔案會出現在「檔案瀏覽器」清單中，但並非可點擊的影像 — 它們提供用於反射率校正的向下輻照度。
* 每個匯入的 `.daq`/`.csv` 檔案都會列於 **專案設定 → DAQ 光感測器** 中，您可在該處檢視每個檔案目前適用的漫射蓋校正值。 請參閱 [調整專案設定](adjusting-project-settings.md)。
* 您在 **光感測器** 索引標籤中進行的記錄會自動新增至開啟中的專案 — 無需手動匯入。***

## 管理專案中的檔案

### 移除檔案

若要從專案中移除不需要的影像：

1. 在「檔案瀏覽器」表格中選取一張或多張影像
2. 點擊 **「移除選取項目」** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> 按鈕
3. 確認移除（檔案不會從磁碟中刪除，僅從專案中移除）

### 排序與篩選

* **按欄位排序**：點擊任何欄位標題即可對圖片進行排序
* **時間戳記排序**：適用於整理按時間順序拍攝的序列
* **相機型號篩選**：若使用多台相機，可依相機類型將圖片分組***

## 圖片預覽

### 檢視完整圖片

點擊檔案瀏覽器中的任何圖片縮圖，即可在主預覽區域中顯示該圖片：

1. 圖片會出現在中央預覽面板中
2. 使用縮放控制項檢視圖片細節
3. 使用方向鍵在圖片間切換

### 快速導覽

* **上一張圖片**：點擊左箭頭或按下 ← 鍵
* **下一張圖片**：點擊右箭頭或按下 → 鍵
* **放大／縮小**：使用滑鼠滾輪或縮放按鈕
* **平移**：放大後點擊並拖曳圖片***

## 重複檔案處理

Chloros 會自動偵測並忽略重複檔案：

* 檔案名稱完全相同的檔案將被跳過
* 防止意外的雙重處理
* 偵測到重複檔案時會顯示警告訊息

{% hint style="warning" %}
**重要提示**：請勿在匯入前重新命名或修改原始影像檔案。Chloros 仰賴原始檔案名稱與元資料才能進行正確處理。
{% endhint %}

***

## 混合相機資料集

若您的專案包含來自多台 MAPIR 相機的影像：

1. Chloros 會自動偵測每台相機的型號 — Survey3、LATTICE 或混合型
2. 每種相機類型皆會使用其對應的校正設定檔進行處理
3. 檔案瀏覽器會在「相機型號」欄位中顯示相機型號
4. 每台相機在處理時都會擁有專屬的輸出資料夾樹

**範例情境**：Survey3W RGN + Survey3N OCN 雙相機配置，或由 RGB 主相機與多個窄帶模組組成的 LATTICE 陣列***

## 最佳實務

### 匯入前進行整理

* 將校正標靶影像與調查影像存放於同一資料夾中
* 將每個拍攝時段的 `.daq` / `.csv` 光感測器檔案與該時段的影像一同存放
* 維持相機／SD 卡／集線器中的原始資料夾結構
* 請勿將不同拍攝時段的資料集混入同一個專案中

### 檔案命名

* 保留原始相機檔案名稱（例如 IMG\_0001.RAW、capture\_... 等）
* 匯入前請勿重新命名檔案
* 原始名稱包含重要的元資料

### 校準目標影像

* 每次拍攝務必包含 1 至 2 張校準目標影像（Survey3；若使用 LATTICE，則可由 DAQ 記錄取代 — 請參閱 [選擇目標影像](choosing-target-images.md))
* 請在拍攝工作階段開始前及結束後分別拍攝標靶
* 將標靶置於與拍攝區域相同的光照條件下
* 使用「標靶」核取方塊標記標靶影像

## 常見問題與解決方案

### 匯入後影像未顯示

**可能原因：**

* 檔案格式不支援（請參閱本頁頂端的「支援的檔案類型」清單）
* 影像來自非 MAPIR 相機（請參閱 [支援的相機](../supported-cameras.md))
* 檔案損毀或從 SD 卡傳輸不完整

**解決方案**：確認檔案格式與相機型號的相容性，並查閱檔案載入警告以確認確切的失敗檔案

### 無法偵測相機型號

**可能原因：**

* EXIF 元資料遭修改
* 影像在外部軟體中經過編輯
* 檔案傳輸不完整

**解決方案**：從相機／SD 卡重新匯入原始、未經修改的檔案

### 缺少時間戳記

**可能原因：**

* 相機時鐘設定不正確
* EXIF 資料遭外部軟體刪除

**解決方案**：確認拍攝時相機的時間設定是否正確

### 重新開啟專案時顯示檔案遺失

若自上次開啟專案以來，來源檔案已被移動或刪除，Chloros 會告知您**哪些**檔案已遺失，而非直接開啟至空白網格。 若專案資料夾本身已移動，Chloros 會將來源路徑重新指向 `project.json` 目前所在的資料夾，並保留備份（`project.json.before-relink-<date>-<time>`）。 若仍無法找到檔案，**「找不到原始檔」**視窗將提供**「瀏覽」**功能以選擇新位置，隨後可選擇**「建立新專案」**或**「刪除專案」**。透過 CLI 請使用 `chloros-cli project open PATH --relink FOLDER`；透過 SDK 則使用 `open_project(path, relink=...)`。***

## 後續步驟

檔案匯入完成後：

1. **檢視檔案清單** — 確認所有影像均已正確載入
2. **檢查相機型號** — 驗證相機偵測是否正確
3. **標記目標影像** — 請參閱 [選擇目標影像](choosing-target-images.md)
4. **調整設定** — 在 [專案設定](adjusting-project-settings.md) 中配置處理選項
5. **開始處理** — 請參閱 [開始處理](starting-the-processing.md)

有關專案配置的詳細資訊，請參閱 [調整專案設定](adjusting-project-settings.md)。
