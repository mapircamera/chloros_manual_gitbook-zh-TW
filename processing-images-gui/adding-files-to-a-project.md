# 将文件添加到项目

在 Chloros 中创建或打开项目后，下一步就是添加多光谱图像以开始处理。通过“文件浏览器”<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 选项卡，可以轻松导入图像并管理数据集。

## 访问文件浏览器

1. 在 Chloros 中打开或创建一个项目
2. 点击左侧边栏中的 **文件浏览器** 图标 <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">
3. 文件浏览器面板将显示您项目的文件列表

{% hint style="info" %}
**支持的文件类型**：

* **Survey3W / Survey3N**：RAW+JPG 对和 JPG 图像 （推荐使用 RAW+JPG）
* **LATTICE**：`.tif` / `.tiff` 捕获数据——由 Chloros 相机控制或 LATTICE 集线器写入
* **光传感器数据**：`.daq` 记录（DAQ-U/M/E）和 DAQ-M `.csv` 下行日志——与图像一同导入以驱动反射率校准
{% endhint %}

***

## 将图像添加到项目中

将图像添加到项目中有两种主要方法：

### 方法 1：添加文件

使用此选项可导入单个图像文件或少量选定文件。

1. 点击“文件浏览器”面板顶部的 **“添加文件”** <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> 按钮
2. 导航至包含图像的文件夹
3. 选择一个或多个图像文件（按住 **Ctrl** 键可选择多个文件）
4. 点击 **“打开”** 以导入所选文件

### 方法 2：添加文件夹

使用此选项可一次性导入文件夹中的所有图像。您可以在一个对话框中选择 **多个文件夹**。

1. 点击文件浏览器面板顶部的 **“添加文件夹”** <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> 按钮
2. 导航至并选择包含您的捕获会话图片的文件夹
3. 点击 **“选择文件夹”** 以导入所有受支持的图片

{% hint style="info" %}
**系统会报告加载失败的文件。**如果某个文件夹中包含 Chloros 能识别但无法加载的文件，系统会显示警告提示——图像不会在网格中悄无声息地消失。
{% endhint %}

***

## 导入 LATTICE 捕获文件夹

LATTICE 捕获数据以 **每个导出级别一个子文件夹** 的形式保存——例如 `raw/`、`debayered/`、 `radiance/`、`reflectance/`、`preview/`——根目录下会包含对应的 `.daq` 下行数据文件：

```
output/
├── raw/           capture_<timestamp>_SN<serial>_raw.tif
├── debayered/     capture_<timestamp>_SN<serial>_debayered.tif
├── preview/       capture_<timestamp>_SN<serial>_display.tif
└── *.daq          the downwelling reading matched to the capture
```

**将“添加文件夹”指向捕获文件的根目录**（即上文中的 `output/`）。 当所选文件夹本身不包含图像但含有子文件夹时，Chloros 会自动向下遍历这些子文件夹——该级别的子文件夹以及根目录下的 `.daq` 都会被一次性全部导入。**捕获文件的导入方式：*** 每个捕获文件均以**单张图像**的形式导入，并按捕获文件分组（而非每个级别一个条目）。同一捕获文件的其他级别将作为该图像的查看模式显示。
* **处理始终从原始帧开始。** 其他层级虽可查看，但只有 `raw` 会被送入处理管道——对已处理的产品进行重新处理会导致校正效果叠加，因此 Chloros 会被忽略。 重新导入的导出文件绝不能占据捕获的原始数据槽位。
* **未**包含原始数据导入的捕获文件夹可正常保存和显示，但处理过程会跳过该文件夹，并在日志中注明。 （标志 CLI `--input-level` 可在此情况下强制指定入口点——参见 [CLI 参考](../reference/cli-reference.md#what-a-captures-folder-looks-like)。)**LATTICE 集线器会话** 的导入方式相同： 在“添加文件夹”中指定从集线器复制的会话文件夹（其中包含 `raw/` 和 `previews/`），以及任何 DAQ-M `.csv` 下行日志。 如果相机或数据采集卡（DAQ）的校准数据尚未缓存到您的计算机上，Chloros 将在导入时根据序列号自动获取（仅需一次互联网连接）。***

## 了解文件浏览器表格

图像导入后，将显示在一个包含以下列的表格中：

### 文件名

* 相机生成的原始文件名
* 保留相机的命名规则（例如：IMG\_0001.RAW 或 capture\_20260816\_101500\_SN213800234\_raw.tif）

### 时间戳

* 图像拍摄的日期和时间
* 从图像 EXIF 元数据中提取
* 用于光传感器匹配、PPK 同步和校准目标调度

### 相机型号

* 自动检测的相机和滤光片配置
* Survey3 示例：Survey3W\_RGN、Survey3N\_OCN、Survey3W\_RGB
* LATTICE 示例：LATT-M3M-L41-F550、LATT-M3C-L87-FRGN
* 用于应用正确的处理配置文件

### 目标列（复选框）

* 若图像包含校准目标，请勾选此复选框
* 当至少勾选了一张图像时，系统将**仅对已勾选的图像进行扫描**以查找目标
* 详情请参阅 [选择目标图像](choosing-target-images.md)

### 查看图像元数据

点击表格上方右上角的切换按钮，可在图像网格区域中显示所选图像的元数据。

## 项目中的光传感器文件

* `.daq` 和 `.csv` 文件会显示在文件浏览器列表中，但并非可点击的图像——它们提供用于反射率校准的向下辐射通量。
* 每个导入的 `.daq`/`.csv` 文件都会列在 **项目设置 → DAQ 光传感器** 中，您可以在该处查看每个文件当前生效的漫反射盖校正值。 请参阅 [调整项目设置](adjusting-project-settings.md)。
* 您在 **光传感器** 选项卡中进行的记录会自动添加到当前打开的项目中——无需手动导入。***

## 管理项目中的文件

### 删除文件

要从项目中删除不需要的图像：

1. 在“文件浏览器”表格中选择一张或多张图像
2. 点击 **“删除所选”** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> 按钮
3. 确认删除（文件不会从磁盘中删除，仅从项目中移除）

### 排序和筛选

* **按列排序**：点击任意列标题即可对图片进行排序
* **按时间戳排序**：适用于整理按时间顺序拍摄的图片序列
* **按相机型号筛选**：若使用多台相机，可按相机类型对图片进行分组***

## 图像预览

### 查看完整图像

在文件浏览器中点击任意图像缩略图，即可在主预览区域中显示该图像：

1. 图像将显示在中央预览面板中
2. 使用缩放控件查看图像细节
3. 使用方向键在图像之间切换

### 快速导航

* **上一张图片**：点击左箭头或按 ← 键
* **下一张图片**：点击右箭头或按 → 键
* **放大/缩小**：使用鼠标滚轮或缩放按钮
* **平移**：放大后点击并拖动图片***

## 重复文件的处理

Chloros 会自动检测并忽略重复文件：

* 文件名完全相同的文件将被跳过
* 防止意外的重复处理
* 检测到重复文件时会显示警告信息

{% hint style="warning" %}
**重要提示**：导入前请勿重命名或修改原始图像文件。Chloros 依赖原始文件名和元数据进行正确处理。
{% endhint %}

***

## 混合相机数据集

如果您的项目包含来自多台 MAPIR 相机的图像：

1. Chloros 会自动检测每台相机的型号——Survey3、LATTICE 或混合型号
2. 每种相机类型均使用相应的校准配置文件进行处理
3. 文件浏览器会在“相机型号”列中显示相机型号
4. 处理时，每台相机都会拥有独立的输出文件夹树

**示例场景**：Survey3W、RGN + Survey3N、OCN 双相机配置， 或由 RGB 主相机和多个窄带模块组成的 LATTICE 阵列***

## 最佳实践

### 导入前进行整理

* 将校准目标图像与勘测图像保存在同一文件夹中
* 将每次拍摄会话的 `.daq` / `.csv` 光传感器文件与该会话的图像保存在一起
* 保留相机/SD卡/集线器中的原始文件夹结构
* 不要将不同拍摄会话的数据集混入同一个项目中

### 文件命名

* 保留原始相机文件名（IMG\_0001.RAW、capture\_... 等）
* 导入前不要重命名文件
* 原始文件名包含重要的元数据

### 校准目标图像

* 每次拍摄会话务必包含 1-2 张校准目标图像（Survey3；对于 LATTICE，可用 DAQ 记录代替——参见 [选择目标图像](choosing-target-images.md))
* 在采集会话开始前和结束后分别拍摄校准目标图像
* 将校准目标置于与采集区域相同的光照条件下
* 使用“Target”复选框标记校准目标图像

## 常见问题及解决方案

### 导入后图像未显示

**可能原因：**

* 文件格式不受支持（参见本页顶部的“支持的文件类型”列表）
* 图像来自非MAPIR相机（参见[支持的相机](../supported-cameras.md))
* 文件损坏或从 SD 卡传输不完整

**解决方案**：验证文件格式与相机型号的兼容性，并查看文件加载警告以确定具体失败的文件

### 未检测到相机型号

**可能原因：**

* EXIF 元数据被修改
* 图片在外部软件中被编辑
* 文件传输不完整

**解决方案**：从相机/SD卡重新导入原始、未经修改的文件

### 缺少时间戳

**可能原因：**

* 相机时钟设置不正确
* EXIF数据被外部软件删除

**解决方案**： 确认拍摄时相机的时间设置是否正确

### 重新打开项目时报告文件缺失

如果自上次打开项目以来源文件已被移动或删除，Chloros 会告知您**哪些**文件已丢失，而不是直接打开一个空白网格。 请将文件恢复到原始路径，或删除缺失的条目并重新导入。***

## 后续步骤

文件导入完成后：

1. **检查文件列表** - 确保所有图像均已正确加载
2. **检查相机型号** - 验证相机检测是否正确
3. **标记目标图像** - 参见 [选择目标图像](choosing-target-images.md)
4. **调整设置** - 在 [项目设置](adjusting-project-settings.md) 中配置处理选项
5. **开始处理** - 请参阅 [开始处理](starting-the-processing.md)

有关项目配置的详细信息，请参阅 [调整项目设置](adjusting-project-settings.md)。
