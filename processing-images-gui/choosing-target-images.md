# 選擇目標影像

標記哪些影像包含校準目標，可讓 Chloros 精確知道該在何處尋找這些目標。當「目標」欄位中至少有一張影像被勾選時，Chloros 將**僅掃描已勾選的影像**——因此，標記目標既能加快處理速度，也能避免將調查影像誤判為目標。

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

## 為何要標記目標影像？

### 標記可控制掃描範圍

當您在「目標」欄位中勾選特定影像時：

* Chloros 僅會掃描已勾選的影像以尋找目標
* 目標偵測速度大幅提升
* 調查影像不會產生錯誤的目標偵測結果

若**未**勾選任何影像，Chloros 將改為掃描專案中的每張影像：

* 目標偵測演算法會對每張影像執行
* 會不必要地檢查數百或數千張影像
* 處理時間將大幅延長，特別是針對大型資料集時

{% hint style="success" %}
**速度提升**：在 500 張影像的資料集中標記 2 至 3 張目標影像，可將目標偵測時間從 30 多分鐘縮短至 1 分鐘以內。
{% endhint %}

***

## 如何標記目標影像

### 步驟 1：識別目標影像

在「檔案瀏覽器」中瀏覽已匯入的影像，並識別哪些影像包含校準目標。

**常見情境：**

* **拍攝前目標**：在開始拍攝 session 之前拍攝
* **拍攝後標靶**：在完成拍攝會話後拍攝
* **現場標靶**：放置於拍攝區域內的標靶
* **多個標靶**：每個拍攝會話包含 2 至 3 張標靶影像（建議）

### 步驟 2：檢查「標靶」欄位 <img src="../.gitbook/assets/image (33).png" alt="" data-size="original">

針對每張包含校準標靶的影像：

1. 在「檔案瀏覽器」表格中找到該影像
2. 找到 **「標靶」** 欄位（最右側的欄位）
3. 勾選該影像在「標靶」欄位中的核取方塊
4. 對所有包含標靶的影像重複上述步驟

### 步驟 3：驗證您的選取範圍

在進行處理前，請再次確認：

* [ ] 所有含有校準標靶的影像均已勾選
* [ ] 沒有誤勾選非標靶影像
* [ ] 已勾選的影像中，標靶清晰可見

***

## LATTICE：當 DAQ 正在錄製時，標靶為選用項目

對於 LATTICE 多光譜相機，畫面內的校準標靶是 **兩種** 可能的反射率參考之一：

* **畫面內標靶**：當標記好的標靶影像通過 Chloros 的品質（QA）門檻時，該標靶即成為其周圍影像的**絕對反射率參考**。
* **DAQ 下行輻照度**：當沒有標靶存在（或 QA 檢查未通過）時，Chloros 會改以 DAQ 光感測器的下行輻照度來計算反射率（ρ = π·L/E）。 若您的擷取範圍涵蓋 `.daq` 或 DAQ-M `.csv` 的記錄資料，您將獲得**完全無需任何目標影像** 的校正反射率。

此自動行為為預設設定。 在 CLI/SDK 中，這對應於 `--reflectance-source auto`；您也可以強制使用 `target`（嚴格模式 — 不進行 DAQ 替代）或 `daq`（DAQ 優先模式）。 請參閱 [CLI 參考手冊](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral)。

**LATTICE 目標幾何形狀**：除了用於 Survey3 的經典面板偵測外，LATTICE 處理還支援**ArUco 標記目標**、**固定 ROI 目標**以及**條狀目標**，並可依專案進行配置。 可透過序列號提供各單位的**測量** 目標反射率掃描資料（CLI：`--target-reflectance-dir`，每個目標單位對應一個 `<serial>.csv`），並以標稱 T3/T4P 光譜作為備用。

{% hint style="info" %}
**F988 模組**：F988 的反射率是透過現場反射率面板進行校準的：由於該波段超出 DAQ 光感測器的校準範圍，因此 Chloros 會套用您最近的面板擷取資料，並在兩次面板觀測之間維持該值。 若 F988 模組僅以 DAQ 方式處理，Chloros 將拒絕該波段基於 DAQ 的反射率（跳過原因 `dls-uncalibrated-band-988`）—— 反射板工作流程才是受支援的處理方式。
{% endhint %}

## 目標影像的最佳實務

### 目標影像擷取指南

**時機：**

* 請在擷取作業開始前立即，以及整個擷取過程中持續擷取目標影像
* 需在與 DAQ 光感測器相同的照明條件下進行
* 為獲得最佳結果，建議盡可能頻繁地擷取目標影像。 否則，系統將隨時間推移使用光感測器數據來調整校準。

**相機位置：**

* 將相機置於目標上方，確保目標居中且佔據影像中心的 40-60% 左右。
* 保持相機與目標表面平行／垂直

**照明：**

* 環境光線應與您的 DAQ 光感測器相同
* 避免目標表面出現陰影
* 請勿以身體、車輛或植被遮擋光源
* 多雲天氣可提供最穩定的結果

**目標狀態：**

* 保持目標面板清潔且乾燥
* 目標的所有面板（例如 T4 上的 4 個面板）應清晰可見且無遮擋
* 若可能，請將目標與光源保持垂直或正對下方

### 需要多少張目標影像？

**最低要求：**每次拍攝至少 1 張目標影像。**建議：** 每次拍攝 3 至 5 張目標影像。**最佳實務時程：**

* 在光感測器開始記錄後不久，立即拍攝 3 至 5 張影像
* 為獲得最佳效果，請在每次拍攝之間旋轉相機
* 可選：若光線條件不斷變化，可在拍攝過程中定期拍攝

## 多相機操作

### 雙相機配置

若同時使用兩台 MAPIR 相機（例如：Survey3W RGN + Survey3N OCN）：

1. 讓 **兩台相機** 同時拍攝標靶影像
2. 兩台相機均使用 **同一實體標靶**

3. 在檔案瀏覽器中標記**兩種相機類型** 的目標影像
4. Chloros 將為每台相機選用適當的目標進行校準

### 相機型號欄位

**相機型號** 欄位有助於辨識哪些影像來自哪台相機：

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* 等

請利用此欄位確認您已在專案中為每種相機類型標記了目標。

## 目標偵測設定

### 調整偵測靈敏度

若 Chloros 無法正確偵測您的目標，請在 [專案設定](adjusting-project-settings.md) 中調整以下設定：

**最小校準樣本面積 (px)：**

* **預設值**：25 像素
* 若在小型瑕疵處出現誤偵測，請**增加**此數值
* 若目標無法被偵測到，請**減少**此數值

**最小目標聚類值 (0-100)：**

* **預設值**：60
* **若目標被分割成多個偵測結果，請** **增加**
* **若顏色變化較大的目標未能完全偵測到，請** **減少**
{% hint style="info" %}
**命令列介面（CLI）提示**：`chloros-cli process` 支援相同的參數（`--min-target-size`、 `--target-clustering`），且其 `--target`/`--targets` 標記可將整個輸入資料夾標記為「僅限目標面板」。 請參閱 [CLI 參考手冊](../reference/cli-reference.md)。
{% endhint %}

## 常見目標影像問題

### 問題：未偵測到目標

**可能原因：**

* 目標影像未在「檔案瀏覽器」中標記
* 畫面中的目標過小（小於影像的 30%）
* 光線條件不佳（陰影、眩光）
* 目標偵測設定過於嚴格

**解決方案：**

1. 確認「目標」欄位已針對正確的影像勾選
2. 在預覽中檢查目標影像品質
3. 若畫質不佳，請重新擷取目標
4. 如有需要，請調整目標偵測設定

### 問題：錯誤偵測目標

**可能原因：**

* 白色建築物、車輛或地面植被被誤判為目標
* 植被中的明亮區域
* 偵測靈敏度過低

**解決方案：**

1. 僅標記實際目標影像 — 僅會掃描已勾選的影像
2. 增加最小校準樣本面積
3. 提高最小目標聚類值
4. 確保目標影像中僅顯示目標（背景雜訊盡量減少）

## 驗證檢查清單

在開始處理之前，請驗證您的目標影像選取：

* [ ] 每個作業階段至少標記 1 張目標影像（或對於 LATTICE，需有涵蓋該作業階段的 `.daq`/`.csv` 錄製檔）
* [ ] 所有目標影像的「目標」欄位複選框均已勾選
* [ ] 目標影像的擷取時間與調查時間範圍一致
* [ ] 點擊預覽時，目標清晰可見
* [ ] 每張目標影像中皆可見所有校準面板
* [ ] 目標上無陰影或遮擋物
* [ ] 雙鏡頭配置：兩種鏡頭類型均已標記目標

## 無目標影像處理

### LATTICE：使用 DAQ 錄製檔

若在 LATTICE 擷取期間，DAQ 光感測器已記錄下行輻照度，則無需目標：

1. 匯入包含影像的 `.daq`（或 DAQ-M `.csv`）檔案
2. 保持「標靶」欄位未勾選
3. 系統會自動根據 DAQ 的向下輻照度參考值計算反射率
4. 輻度（Radiance）永遠不需要目標或 DAQ —— 它僅來自相機的出廠輻度校準

### 無任何參考資料的處理

您也可以在不使用目標和 DAQ 的情況下進行處理：

1. 將所有「目標」欄位的核取方塊保持未勾選狀態
2. 在「專案設定」中**停用**「反射率校正／白平衡」——如此一來將完全跳過標靶偵測
3. 暗角校正仍會套用
4. 輸出結果不會針對絕對反射率進行校正（LATTICE 多光譜仍會匯出去拜耳化、預覽及輻照度產品）

{% hint style="warning" %}
**不建議用於 Survey3 科學研究**：若未進行反射率校正，Survey3 的像素值僅代表相對亮度，而非科學反射率測量值。請使用校正標靶（或對於 LATTICE，使用 DAQ 光感測器），以獲得準確且可重複的結果。
{% endhint %}
