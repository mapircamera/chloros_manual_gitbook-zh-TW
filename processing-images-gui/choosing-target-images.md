# 选择目标图像

标记哪些图像包含校准目标，可以告诉 Chloros 确切的搜索位置。当“目标”列中至少有一张图像被选中时，Chloros 只会扫描 **选中的图像**——因此，标记目标既能加快处理速度，又能避免将勘测图像误认为目标。

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

## 为什么要标记目标图像？

### 标记控制扫描范围

当您在“目标”列中勾选特定图像时：

* Chloros 仅对已勾选的图像进行目标扫描
* 目标检测速度大大加快
* 调查图像不会产生错误的目标检测结果

如果**未**勾选任何图像，Chloros将转为扫描项目中的每张图像：

* 目标检测算法会对每张图像运行
* 数百或数千张图像会被不必要地检查
* 处理时间会显著延长，尤其是对于大型数据集

{% hint style="success" %}
**速度提升**：在 500 张图像的数据集中标记 2-3 张目标图像，可将目标检测时间从 30 多分钟缩短至 1 分钟以内。
{% endhint %}

***

## 如何标记目标图像

### 步骤 1：识别目标图像

在“文件浏览器”中浏览已导入的图像，并识别出哪些图像包含校准目标。

**常见情况：*** **拍摄前目标**：在开始拍摄会话前捕获
* **拍摄后目标**：在完成拍摄会话后拍摄
* **现场目标**：放置在拍摄区域内的目标
* **多个目标**：每个会话包含 2-3 张目标图像（推荐）

### 步骤 2：检查“目标”列 <img src="../.gitbook/assets/image (33).png" alt="" data-size="original">

对于每张包含校准目标的图像：

1. 在“文件浏览器”表格中定位该图像
2. 找到 **“目标”** 列（最右侧一列）
3. 勾选该图像所在“目标”列中的复选框
4. 对所有包含校准目标的图像重复此操作

### 步骤 3：验证您的选择

在处理之前，请仔细核对：

* [ ] 所有包含校准目标的图像均已勾选
* [ ] 没有误勾选非目标图像
* [ ] 已勾选的图像中校准目标清晰可见

## LATTICE：当数据采集（DAQ）正在记录时，校准目标为可选项

对于 LATTICE 多光谱相机，帧内校准目标是 **两种** 可能的反射率参考之一：

* **帧内校准目标**：当标记好的目标图像通过Chloros的质量（QA）门限时，该目标即成为其周围图像的**绝对反射率参考**。
* **DAQ下行辐照度**：当不存在目标（或QA检测失败）时，Chloros将根据DAQ光传感器的下行辐照度计算反射率（ρ = π·L/E）。 如果您的捕获数据包含 `.daq` 或 DAQ-M `.csv` 的记录，您将获得校准后的反射率，**而完全无需任何目标图像**。

此自动行为是默认设置。 在 CLI / SDK 中，这对应于 `--reflectance-source auto`；您也可以强制使用 `target`（严格模式——不进行 DAQ 替换）或 `daq`（DAQ 优先）。 请参阅 [CLI 参考文档](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral)。

**LATTICE 目标几何形状**：除了用于 Survey3 的经典面板检测外，LATTICE 处理还支持**ArUco 标记目标**、**固定 ROI 目标**和**条带目标**，这些均可根据项目进行配置。 每个单元的**实测**靶标反射率扫描数据可通过序列号提供（CLI：`--target-reflectance-dir`，每个靶标单元对应一个`<serial>.csv`），并以标称的T3/T4P光谱作为备用方案。

{% hint style="info" %}
**F988模块**：F988的反射率使用现场反射率面板进行校准：由于该波段超出了DAQ光传感器的校准范围，因此Chloros会应用您最近的面板捕获数据，并在两次面板观测之间保持该值。 如果 F988 模块仅通过 DAQ 进行处理，Chloros 将拒绝该波段基于 DAQ 的反射率（跳过原因 `dls-uncalibrated-band-988`）——面板工作流是受支持的处理路径。
{% endhint %}

## 目标图像的最佳实践

### 目标图像采集指南

**时间安排：**

* 在采集会话开始前立即以及整个采集过程中采集目标图像
* 确保与 DAQ 光传感器处于相同的照明条件下
* 为获得最佳效果，建议尽可能频繁地采集目标图像。否则，系统将使用光传感器数据随时间推移调整校准。

**相机位置：**

* 将相机置于目标上方，确保目标居中且占据图像中心的约 40-60%。
* 保持相机与目标表面平行或正对目标表面

**照明：**

* 环境光线应与您的数据采集（DAQ）光传感器保持一致
* 避免目标表面出现阴影
* 不要用身体、车辆或植被遮挡光源
* 多云天气可提供最稳定的结果

**目标状态：**

* 保持目标面板清洁干燥
* 目标的所有面板（例如 T4 上的全部 4 个）应清晰可见且无遮挡
* 尽可能使目标与光源呈垂直/正下方位置

### 需要多少张目标图像？

**最低要求：**每次拍摄至少 1 张目标图像。**建议：** 每次拍摄 3-5 张目标图像。**最佳实践计划：**

* 在光传感器开始记录后不久拍摄 3-5 张图像
* 每次拍摄之间旋转相机以获得最佳效果
* 可选：若光照条件持续变化，可在拍摄过程中定期重拍

## 多摄像头操作

### 双摄像头设置

若同时使用两台MAPIR摄像头（例如：Survey3W RGN + Survey3N OCN）：

1. 使用**两台摄像头**同时拍摄目标图像
2. 确保两台相机使用**同一物理目标**

3. 在文件浏览器中标记**两种相机类型**的目标图像
4. Chloros 将为每台相机的校准选用相应目标

### “相机型号”列

“**相机型号**”列有助于识别哪些图像来自哪台相机：

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* 等

请使用此列核对您是否已在项目中为每种相机类型标记了目标。

## 目标检测设置

### 调整检测灵敏度

如果“Chloros”无法正确检测目标，请在 [项目设置](adjusting-project-settings.md) 中调整以下设置：

**最小校准采样面积 (px)：*** **默认值**：25 像素
* **增大**该值，若在微小伪影上出现误检
* **减小**该值，若目标无法被检测到**最小目标聚类值（0-100）：*** **默认值**：60
* **若目标被拆分为多个检测结果，请** **增加*** **若颜色变化较大的目标未被完全检测到，请** **减少**{% hint style="info" %}**关于 CLI 的提示**：`chloros-cli process` 支持相同的调节参数（`--min-target-size`、 `--target-clustering`），其 `--target`/`--targets` 标志可将整个输入文件夹标记为“仅限目标面板”。 请参阅 [CLI 参考文档](../reference/cli-reference.md)。
{% endhint %}

## 常见目标图像问题

### 问题：未检测到目标

**可能原因：**

* 目标图像在文件浏览器中未被标记
* 目标在画面中过小（小于图像的 30%）
* 光线条件不佳（阴影、眩光）
* 目标检测设置过于严格

**解决方案：**

1. 确认“目标”列中已选中正确的图像
2. 在预览中检查目标图像质量
3. 若质量不佳，请重新采集目标图像
4. 如有必要，调整目标检测设置

### 问题：误检目标

**可能原因：**

* 白色建筑物、车辆或地面覆盖物被误认为目标
* 植被中的亮斑
* 检测灵敏度过低

**解决方案：**

1. 仅标记实际目标图像——仅已勾选的图像会被扫描
2. 增加最小校准样本面积
3. 提高最小目标聚类值
4. 确保目标图像中仅显示目标（背景杂波最少）

## 无目标处理

### LATTICE：使用 DAQ 记录

如果在 LATTICE 拍摄期间，DAQ 光传感器记录了向下辐射通量，则无需目标：

1. 导入包含图像的 `.daq`（或 DAQ-M `.csv`）文件
2. 保持“目标”列未勾选
3. 系统将自动根据 DAQ 向下辐射参考值计算反射率
4. 辐射度处理无需目标或DAQ数据——它完全由相机的出厂辐射校准提供

### 无任何参考数据的处理

您也可以在不使用目标和DAQ的情况下进行处理：

1. 保持所有“目标”列复选框未勾选
2. 在“项目设置”中**禁用**“反射率校准/白平衡”——此时将完全跳过目标检测
3. 暗角校正仍会应用
4. 输出结果不会针对绝对反射率进行校准（LATTICE 多光谱仍会导出去拜耳化、预览和辐射度产品）

{% hint style="warning" %}
**不建议用于Survey3的科研工作**：若未进行反射率校准，Survey3的像素值仅代表相对亮度，而非科学反射率测量值。请使用校准目标（或对于LATTICE，使用DAQ光传感器）以获得准确、可重复的结果。
{% endhint %}
